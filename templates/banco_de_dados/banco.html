1. Introdução a Bancos de Dados

Imagine uma biblioteca enorme com milhares de livros sem nenhuma organização — encontrar qualquer coisa seria impossível. Um banco de dados resolve exatamente isso para as informações digitais: é um sistema organizado para armazenar, gerenciar e recuperar dados com eficiência.

- O que é um Banco de Dados?

Um banco de dados é uma coleção organizada de dados que podem ser facilmente acessados e atualizados. Eles estão presentes em tudo ao seu redor:

  • Quando você faz login em um aplicativo → banco de dados de usuários
  • Quando compra algo online → banco de dados de produtos e pedidos
  • Quando usa o cartão no caixa → banco do seu banco consultado em milissegundos
  • Quando posta em uma rede social → banco de dados de posts e curtidas

- SGBD: O Software que Gerencia

O Sistema de Gerenciamento de Banco de Dados (SGBD) é o software que fica entre o usuário e os dados. Os mais usados no mercado são:

  • MySQL / MariaDB — gratuitos, amplamente usados em sites e aplicações web
  • PostgreSQL — poderoso, código aberto, muito popular em empresas
  • SQLite — embutido em aplicativos móveis e usado neste curso!
  • SQL Server — solução da Microsoft para ambientes corporativos

- Por que aprender SQL?

SQL (Structured Query Language) é a linguagem universal para consultar bancos de dados relacionais. Desenvolvedores, analistas de dados e até profissionais de marketing precisam dela. É uma das habilidades mais valorizadas no mercado de tecnologia.

- Bancos Relacionais vs Não-Relacionais

Nem todo banco de dados organiza informação em tabelas. Existem dois grandes grupos:

  • Relacionais (SQL): dados em tabelas com linhas e colunas, relacionadas entre si por chaves. Ex: MySQL, PostgreSQL, SQLite — foco deste curso.
  • Não-relacionais (NoSQL): dados em documentos, grafos ou chave-valor, sem esquema rígido. Ex: MongoDB, Redis — úteis quando o volume é enorme ou o formato dos dados varia muito.
Qual escolher?
Bancos relacionais continuam sendo a escolha padrão para a maioria dos sistemas — e-commerce, sistemas financeiros, redes sociais no seu núcleo — justamente por garantirem consistência dos dados através de relacionamentos bem definidos.

- Erros Comuns de Quem Está Começando

Fique de olho nestas armadilhas
  • Esquecer o ponto e vírgula ; no final do comando SQL.
  • Confundir aspas simples de texto ('texto') com aspas de identificador de tabela/coluna.
  • SQL não é case-sensitive nas palavras-chave — SELECT e select funcionam igual — mas é convenção usar maiúsculas para os comandos.
