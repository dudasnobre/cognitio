6. INSERT, UPDATE e DELETE — Manipulando Dados

Além de consultar, você precisa inserir, atualizar e remover dados. Esses comandos formam o DML (Data Manipulation Language) do SQL.

- INSERT: Inserindo Dados

-- Inserir um cliente
INSERT INTO clientes (nome, email, cidade, saldo)
VALUES ('Fábio Santos', 'fabio@email.com', 'Fortaleza', 2100.00);

-- Inserir vários de uma vez
INSERT INTO clientes (nome, cidade)
VALUES ('Gabi Lima', 'Recife'), ('Hugo Torres', 'Manaus');

- UPDATE: Atualizando Dados

-- Atualiza o saldo do cliente id=1
UPDATE clientes SET saldo = 2000.00 WHERE id = 1;

-- Dar 10% de bônus para todos de SP
UPDATE clientes SET saldo = saldo * 1.10
WHERE cidade = 'São Paulo';
CUIDADO: UPDATE sem WHERE atualiza todos os registros. Sempre use WHERE para limitar o impacto. Na dúvida, teste com um SELECT primeiro!

- DELETE: Removendo Dados

-- Remove um produto específico
DELETE FROM produtos WHERE id = 6;

-- Remove produtos sem estoque
DELETE FROM produtos WHERE estoque = 0;
DELETE sem WHERE apaga todos os registros da tabela! Os dados não têm lixeira — se deletar sem querer, use o botão "Resetar BD".
Fluxo seguro:
1. Faça um SELECT com o mesmo WHERE para conferir o que será afetado.
2. Se estiver correto, execute o UPDATE ou DELETE.

- Transações (Uma Introdução)

Em bancos usados em produção, comandos de manipulação costumam rodar dentro de uma transação — um bloco onde tudo acontece por completo ou nada acontece:

BEGIN TRANSACTION;
UPDATE contas SET saldo = saldo - 100 WHERE id = 1;
UPDATE contas SET saldo = saldo + 100 WHERE id = 2;
COMMIT;   -- confirma as duas alterações
-- ou ROLLBACK; para desfazer tudo se algo der errado
Por que isso importa
Imagine uma transferência bancária: se o débito de uma conta acontecer mas o crédito na outra falhar, o dinheiro simplesmente desaparece. Transações garantem que as duas operações aconteçam juntas, ou nenhuma delas acontece.
Exercício rápido
No terminal abaixo, insira um novo produto com INSERT, depois use UPDATE para reduzir seu estoque em 1 unidade, e por fim confira o resultado com um SELECT.

- Resumo do Módulo

  • INSERT INTO tabela (colunas) VALUES (valores); adiciona novos registros
  • UPDATE tabela SET coluna = valor WHERE condição; altera registros existentes
  • DELETE FROM tabela WHERE condição; remove registros
  • Nunca rode UPDATE/DELETE sem WHERE, a menos que essa seja mesmo sua intenção
