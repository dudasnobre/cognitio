3. SELECT — Consultando Dados

O SELECT é o comando mais importante do SQL. Com ele você consulta dados de uma tabela — é como fazer uma pergunta ao banco: "Me mostre esses dados!"

- Sintaxe Básica

Para buscar todas as colunas de uma tabela, use o asterisco *:

SELECT * FROM clientes;

Para escolher colunas específicas:

SELECT nome, cidade FROM clientes;

- Alias: Renomeando Colunas no Resultado

SELECT
    nome   AS "Nome do Cliente",
    saldo  AS "Saldo R$"
FROM clientes;

- Expressões no SELECT

Você pode fazer cálculos diretamente:

SELECT nome, saldo, saldo * 0.10 AS rendimento
FROM clientes;

- SELECT sem tabela

O SELECT pode ser usado para testar expressões:

SELECT 2 + 2 AS resultado;
SELECT date('now') AS hoje;
SELECT upper('cognitio') AS maiusculo;
Boa prática
Escreva palavras-chave SQL em MAIÚSCULAS (SELECT, FROM) e nomes de colunas em minúsculas. Não é obrigatório, mas é a convenção do mercado.

- DISTINCT: Removendo Duplicatas

Quando você quer saber quais valores diferentes existem numa coluna, sem repetição, use DISTINCT:

SELECT DISTINCT cidade FROM clientes;

Se houver 50 clientes mas só 4 cidades diferentes, o resultado mostrará essas 4 cidades uma única vez cada.

* traz tudo — use com cuidado
SELECT * é ótimo para explorar dados no dia a dia, mas em sistemas reais é melhor listar as colunas que você realmente precisa — traz menos dados pela rede e deixa claro o que a consulta espera receber.

- Resumo do Módulo

  • SELECT coluna1, coluna2 FROM tabela; busca colunas específicas
  • * traz todas as colunas — útil para explorar, evite em produção
  • AS renomeia colunas no resultado (alias)
  • DISTINCT remove valores duplicados do resultado
