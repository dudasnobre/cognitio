8. Subconsultas (Subqueries)

Uma subconsulta é uma consulta SELECT dentro de outra consulta. Ela permite responder perguntas em duas etapas: primeiro calcule algo, depois use esse resultado para filtrar ou comparar.

- Subconsulta no WHERE

-- Clientes com saldo acima da média
SELECT nome, saldo
FROM clientes
WHERE saldo > (SELECT AVG(saldo) FROM clientes);

O banco primeiro calcula a subconsulta (SELECT AVG(saldo) FROM clientes), obtém um único valor, e então usa esse valor para filtrar a consulta externa.

- Subconsulta com IN

-- Produtos que já foram pedidos ao menos uma vez
SELECT nome, preco
FROM produtos
WHERE id IN (SELECT DISTINCT produto_id FROM pedidos);

- Subconsulta Correlacionada

-- Clientes cujo saldo é maior que a média de saldo da PRÓPRIA cidade
SELECT c1.nome, c1.cidade, c1.saldo
FROM clientes c1
WHERE c1.saldo > (
    SELECT AVG(c2.saldo) FROM clientes c2 WHERE c2.cidade = c1.cidade
);

Diferente da subconsulta comum, a subconsulta correlacionada faz referência a uma coluna da consulta externa (c1.cidade) — por isso ela é recalculada para cada linha.

- Subconsulta no FROM

-- Total gasto por cliente, filtrando depois quem gastou mais de 500
SELECT * FROM (
    SELECT c.nome, SUM(pe.quantidade * p.preco) AS total_gasto
    FROM clientes c
    JOIN pedidos pe ON c.id = pe.cliente_id
    JOIN produtos p ON p.id = pe.produto_id
    GROUP BY c.id
) AS resumo
WHERE total_gasto > 500;

Uma subconsulta no FROM é tratada como se fosse uma tabela temporária, permitindo filtrar (WHERE) sobre um resultado já agregado — algo que HAVING sozinho nem sempre resolve com a mesma clareza.

EXISTS costuma ser mais eficiente que IN
Para checar apenas "existe pelo menos uma linha correspondente", WHERE EXISTS (SELECT 1 FROM pedidos WHERE cliente_id = c.id) costuma ser mais rápido que um IN com uma subconsulta grande, porque o banco pode parar assim que encontra a primeira ocorrência.
Subconsulta deve retornar o formato certo
Uma subconsulta usada com = ou em uma comparação simples deve retornar exatamente uma linha e uma coluna. Se ela puder retornar várias linhas, use IN em vez de =.

- Resumo do Módulo

  • Subconsultas permitem usar o resultado de um SELECT dentro de outro
  • IN compara com uma lista de valores retornada pela subconsulta
  • Subconsultas correlacionadas fazem referência à consulta externa e recalculam por linha
  • Subconsulta no FROM funciona como uma tabela temporária
