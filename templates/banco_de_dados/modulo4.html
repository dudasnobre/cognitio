4. WHERE e ORDER BY — Filtrando e Ordenando

O WHERE filtra registros: "Só me mostre os clientes de São Paulo". O ORDER BY organiza os resultados em ordem crescente ou decrescente.

- WHERE: Filtrando Registros

SELECT * FROM clientes
WHERE cidade = 'São Paulo';

- Operadores de Comparação

  • = igual  ·  != diferente  ·  < / > menor/maior
  • BETWEEN x AND y — entre dois valores
  • IN (a, b, c) — dentro de uma lista
  • LIKE 'A%' — começa com A (% = qualquer coisa)
  • IS NULL / IS NOT NULL — verifica valor nulo

- Combinando Condições

-- AND: ambas as condições verdadeiras
SELECT nome, saldo FROM clientes
WHERE saldo > 1000 AND cidade != 'Salvador';

-- IN: clientes dessas cidades
SELECT * FROM clientes
WHERE cidade IN ('São Paulo', 'Curitiba');

- ORDER BY: Ordenando

-- Decrescente: mais rico primeiro
SELECT * FROM clientes ORDER BY saldo DESC;

-- Crescente (padrão = ASC)
SELECT * FROM clientes ORDER BY nome ASC;

- LIMIT: Limitando Resultados

-- Top 3 clientes mais ricos
SELECT nome, saldo FROM clientes
ORDER BY saldo DESC
LIMIT 3;
Ordem de execução SQL:
FROM → WHERE → SELECT → ORDER BY → LIMIT. O banco filtra antes de selecionar as colunas.

- ORDER BY com Múltiplas Colunas

Você pode ordenar por mais de uma coluna — o segundo critério só é usado para desempatar o primeiro:

-- Ordena por cidade; dentro de cada cidade, do maior saldo pro menor
SELECT nome, cidade, saldo FROM clientes
ORDER BY cidade ASC, saldo DESC;
LIKE é case-sensitive em alguns bancos
Em SQLite, LIKE 'a%' normalmente ignora maiúsculas/minúsculas para texto ASCII, mas isso varia entre bancos — em PostgreSQL, por exemplo, LIKE é sensível a maiúsculas e você usaria ILIKE para ignorar. Sempre teste no banco que for usar de verdade.
Exercício rápido
No terminal abaixo, escreva uma consulta que mostre os produtos com preço entre 50 e 300, ordenados do mais barato para o mais caro, mostrando só os 5 primeiros.

- Resumo do Módulo

  • WHERE filtra linhas com base em uma condição
  • AND/OR/IN/BETWEEN/LIKE combinam e refinam filtros
  • ORDER BY coluna ASC|DESC ordena o resultado
  • LIMIT n restringe o número de linhas retornadas
