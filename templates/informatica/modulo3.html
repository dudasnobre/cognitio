3. Escrita Profissional (Processador de Texto / Word)

O Word (ou Google Docs) serve para transformar seus pensamentos, ideias e necessidades em documentos oficiais padronizados: currículos, cartas de apresentação, contratos ou trabalhos escolares bem estruturados.

- O Domínio Teclado e suas Teclas de Controle

Escrever no computador vai além de digitar letras. É necessário conhecer as teclas que controlam o comportamento do cursor e atalhos:

  • Ctrl (Control): Tecla de comando especial. Segurar o Ctrl e apertar outra letra ativa um atalho rápido (exemplo: Ctrl + C copia, Ctrl + V cola o texto).
  • Alt (Alternativa): Permite acessar alternativamente menus superiores e ferramentas escondidas das janelas.
  • Shift: Usada para digitar uma única letra maiúscula (segure Shift e aperte a letra) ou ativar os símbolos superiores das teclas (como o ponto de interrogação ou as aspas).
  • Tab: Dá um espaçamento padrão grande para parágrafos no início de um bloco de texto ou pula para o próximo campo de edição.

- Exercício Prático: Formatando um Documento

  1. Corrigindo Erros de Digitação: Caso digite algo errado, não se desespere. Clique com o botão esquerdo do mouse exatamente após a letra incorreta. Use a tecla Backspace (a seta acima do Enter) para apagar para a esquerda e digite a palavra corrigida.
  2. Selecionando Textos para Modificar: O computador só altera aquilo que está selecionado. Para selecionar, clique no início ou final do trecho desejado, segure o botão esquerdo do mouse pressionado e arraste o cursor por cima do texto, cobrindo-o com uma faixa azul.
  3. Aplicando Estilo Profissional: Com o texto selecionado, olhe para a barra de ferramentas superior:
    • Clique no ícone com a letra N para destacar em Negrito títulos importantes.
    • Clique no ícone de linhas centralizadas para alinhar títulos perfeitamente no meio da folha.
    • Altere o tamanho da fonte (número indicador da letra) subindo de 11 para 14 para criar títulos destacados.

- Salvando seu Documento Corretamente

Nunca confie apenas na memória do computador — salve com frequência! Pressione Ctrl + S (de "Save", salvar) a cada poucos minutos de trabalho. Na primeira vez, o programa vai pedir um nome e um local para guardar o arquivo — escolha uma pasta que você lembre facilmente, como "Meus Documentos".

Atalhos essenciais do Word
Ctrl+Z desfaz a última ação (seu "botão de arrependimento"). Ctrl+B aplica negrito. Ctrl+I aplica itálico. Ctrl+P abre a impressão.

- Verificador Ortográfico: Seu Revisor Automático

Se uma palavra aparecer sublinhada em vermelho ondulado, o Word está avisando que ela pode estar com erro de digitação. Clique com o botão direito sobre a palavra sublinhada para ver sugestões de correção.

O corretor não é infalível
O verificador ortográfico não identifica todos os erros — palavras escritas corretamente mas usadas no contexto errado (como "mas" e "mais") não são sempre detectadas. Sempre releia seu texto antes de enviar um documento importante.
Exercício rápido
Abra o Word (ou Google Docs) e escreva um pequeno currículo com seu nome em negrito e centralizado como título, seguido de 3 tópicos com suas habilidades. Salve o arquivo com Ctrl+S antes de fechar.

- Resumo do Módulo

  • Ctrl, Alt, Shift e Tab são teclas de controle que ativam atalhos e comportamentos especiais
  • Selecionar o texto (arrastando o mouse) é o primeiro passo para formatar qualquer coisa
  • Ctrl+S salva; Ctrl+Z desfaz — use os dois com frequência
