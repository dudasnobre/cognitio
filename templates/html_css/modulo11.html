11. Animações e Transições em CSS

Movimento bem aplicado dá vida a uma interface: um botão que reage ao toque, uma seção que aparece suavemente. CSS oferece dois mecanismos para isso — transition para mudanças simples, e @keyframes para animações mais elaboradas.

- transition: Animando Mudanças de Estado

.botao {
    background: #F77F00;
    transform: scale(1);
    transition: background 0.3s ease, transform 0.2s ease;
}
.botao:hover {
    background: #C96400;
    transform: scale(1.05);
}

transition diz ao navegador: "quando esta propriedade mudar, anime a mudança em vez de trocar instantaneamente". Funciona com :hover, :focus

- transform: Movendo, Girando e Escalando

.card:hover {
    transform: translateY(-8px) scale(1.02);
}
.icone-menu.aberto {
    transform: rotate(90deg);
}
  • translateX/Y — move o elemento sem afetar o layout ao redor
  • scale() — aumenta ou diminui o tamanho
  • rotate() — gira o elemento
Prefira transform e opacity
Animar transform e opacity é muito mais performático do que animar width, top ou margin, porque o navegador não precisa recalcular o layout inteiro a cada quadro.

- @keyframes: Animações com Múltiplas Etapas

@keyframes pulsar {
    0%   { transform: scale(1); opacity: 1; }
    50%  { transform: scale(1.1); opacity: 0.8; }
    100% { transform: scale(1); opacity: 1; }
}

.notificacao {
    animation: pulsar 1.5s ease-in-out infinite;
}

Cada porcentagem representa um momento da animação. O navegador interpola suavemente entre eles.

- Propriedades de animation

  • animation-duration — quanto tempo dura um ciclo
  • animation-iteration-count — quantas vezes repete (infinite para sempre)
  • animation-delay — espera antes de começar
  • animation-timing-function — curva de velocidade (ease, linear, ease-in-out)

- Respeitando prefers-reduced-motion

Algumas pessoas sentem desconforto (tontura, enjoo) com animações intensas. É boa prática — e cada vez mais esperado — respeitar essa preferência do sistema operacional:

@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; transition: none !important; }
}
Excesso de animação prejudica a usabilidade
Anime com intenção: uma transição de 0.2-0.3s em hovers e uma animação de entrada sutil já bastam na maioria dos casos. Movimento constante e chamativo cansa e distrai quem está tentando usar o site.

- Resumo do Módulo

  • transition anima mudanças simples entre dois estados
  • transform (translate/scale/rotate) é a forma mais performática de mover elementos
  • @keyframes + animation criam sequências com várias etapas
  • Sempre respeite prefers-reduced-motion
