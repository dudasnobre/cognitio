12. Pseudo-classes, Pseudo-elementos e Seletores Avançados

Pseudo-classes selecionam elementos com base em um estado (foi clicado? é o primeiro filho?). Pseudo-elementos criam ou direcionam uma parte específica de um elemento. Juntos, eles evitam muito HTML e JavaScript desnecessários.

- Pseudo-classes de Estado

a:hover    { color: #F77F00; }     /* mouse sobre o link */
a:visited  { color: #6c35c9; }     /* link já visitado */
input:focus { border-color: #0ea5b7; }
button:disabled { opacity: 0.5; cursor: not-allowed; }
input:checked + label { font-weight: bold; }

- Pseudo-classes Estruturais

li:first-child  { font-weight: bold; }
li:last-child   { border-bottom: none; }
tr:nth-child(even) { background: #f5f5f5; }   /* linhas zebradas */
p:nth-child(3n)    { color: red; }             /* a cada 3 parágrafos */
li:not(.ativo)     { opacity: 0.6; }
  • nth-child(even)/odd — muito usado para listas e tabelas zebradas
  • :not() — seleciona tudo exceto o que estiver dentro dos parênteses

- Pseudo-elementos: ::before e ::after

.citacao::before {
    content: "\201C";  /* aspas decorativas */
    font-size: 2rem;
    color: #F77F00;
}

.obrigatorio::after {
    content: " *";
    color: #D62828;
}

::before e ::after inserem conteúdo "virtual" antes ou depois do conteúdo real do elemento, controlado inteiramente pelo CSS — sem precisar adicionar uma tag no HTML.

- Combinadores de Seletores

nav a          { }  /* qualquer <a> dentro de nav, em qualquer nível */
nav > a        { }  /* apenas <a> filho DIRETO de nav */
h2 + p         { }  /* apenas o <p> logo depois de um <h2> */
h2 ~ p         { }  /* todo <p> que vem depois de um <h2>, irmão dele */

- :has() — o "seletor pai" (suporte moderno)

/* Seleciona um .card que CONTÉM uma imagem */
.card:has(img) {
    border: 2px solid #0ea5b7;
}
Checkbox hack
A combinação input:checked ~ .menu permite abrir/fechar menus e acordeões usando só HTML e CSS, sem uma linha de JavaScript — útil para interações simples.
::before/::after precisam de content
Sem a propriedade content (mesmo vazia: content: "";), pseudo-elementos simplesmente não aparecem — é o erro mais comum ao usá-los.

- Resumo do Módulo

  • Pseudo-classes (:hover, :nth-child, :not) selecionam por estado ou posição
  • Pseudo-elementos (::before, ::after) inserem conteúdo virtual via CSS
  • Combinadores (>, +, ~) refinam exatamente quais elementos são atingidos
