2. Texto, Listas, Links e Imagens

Agora que você conhece a estrutura básica, vamos ver as tags mais usadas no dia a dia: formatação de texto, listas, links e imagens.

- Formatação de Texto

<strong>Texto em negrito</strong>
<em>Texto em itálico</em>
<span>Um trecho qualquer de texto</span>
<br> <!-- quebra de linha -->

- Listas

Lista não-ordenada (com marcadores):

<ul>
    <li>Café</li>
    <li>Leite</li>
    <li>Açúcar</li>
</ul>

Lista ordenada (numerada):

<ol>
    <li>Ferver a água</li>
    <li>Adicionar o café</li>
    <li>Servir</li>
</ol>

- Links

<a href="https://exemplo.com">Visite o site</a>
<a href="https://exemplo.com" target="_blank">Abre em nova aba</a>
<a href="#secao2">Ir para a Seção 2</a> <!-- link interno -->
Dica
target="_blank" abre o link em uma nova aba. É uma boa prática usar também rel="noopener" junto, por segurança.

- Imagens

<img src="foto.jpg" alt="Descrição da imagem" width="300">
  • src — caminho ou URL da imagem
  • alt — texto alternativo (essencial para acessibilidade e SEO)
  • width/height — dimensões em pixels
Nunca deixe o alt vazio
O atributo alt é lido em voz alta por leitores de tela para pessoas com deficiência visual, e aparece no lugar da imagem se o arquivo não carregar. Escreva algo descritivo, como alt="Gráfico de vendas crescendo em 2025", nunca alt="imagem1".

- Listas de Definição (menos comum, mas útil)

<dl>
    <dt>HTML</dt>
    <dd>Linguagem de marcação da web</dd>
    <dt>CSS</dt>
    <dd>Linguagem de estilização visual</dd>
</dl>
Exercício rápido
No laboratório abaixo, crie uma lista não-ordenada com 3 dos seus filmes favoritos, e um link (com target="_blank") para uma página qualquer.

- Resumo do Módulo

  • <strong> e <em> dão ênfase ao texto (negrito e itálico)
  • <ul>/<ol> com <li> criam listas não-ordenadas e ordenadas
  • <a href="..."> cria links; target="_blank" abre em nova aba
  • <img src="..." alt="..."> exibe imagens — o alt nunca deve ficar vazio
