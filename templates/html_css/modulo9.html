9. CSS Grid Avançado

Você já viu o básico do Grid. Agora vamos dominar as ferramentas que fazem do Grid o sistema ideal para layouts de página inteira: áreas nomeadas, colunas flexíveis automáticas e posicionamento preciso.

- grid-template-areas: Desenhando o Layout

.pagina {
    display: grid;
    grid-template-columns: 220px 1fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "cabecalho cabecalho"
        "menu      conteudo"
        "rodape    rodape";
    min-height: 100vh;
}
header { grid-area: cabecalho; }
nav     { grid-area: menu; }
main    { grid-area: conteudo; }
footer  { grid-area: rodape; }

Você literalmente desenha o layout com texto — cada palavra repetida ocupa aquele espaço na grade. É a forma mais legível de montar uma página inteira com Grid.

- repeat(), auto-fit e auto-fill

.galeria {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
    gap: 16px;
}

Essa linha cria quantas colunas de 180px+ couberem na tela, e distribui o espaço sobrando entre elas — uma grade responsiva completa em uma única linha de CSS, sem media queries.

  • auto-fit — colunas vazias encolhem, os itens existentes esticam para preencher o espaço
  • auto-fill — mantém o espaço reservado para colunas vazias (útil quando o número de itens é sempre parecido)

- Posicionando Itens Manualmente

.destaque {
    grid-column: 1 / 3;   /* ocupa da linha 1 até a linha 3 (2 colunas) */
    grid-row: 1 / 2;
}
/* Atalho equivalente: */
.destaque { grid-column: span 2; }

- Grid dentro de Flexbox (e vice-versa)

Grid e Flexbox não competem — eles se complementam. É muito comum usar Grid para o layout geral da página e Flexbox dentro de cada componente (como um card com ícone + texto alinhados):

.card {
    display: flex;       /* alinhamento interno do card */
    align-items: center;
    gap: 12px;
}
.galeria {
    display: grid;        /* organização geral dos cards */
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
}
fr é sua unidade favorita
1fr significa "uma fração do espaço disponível". grid-template-columns: 2fr 1fr cria duas colunas onde a primeira é sempre o dobro da largura da segunda, em qualquer tamanho de tela.
Nomes de área precisam bater exatamente
O valor em grid-area precisa ser idêntico ao nome usado em grid-template-areas (mesma grafia, sem espaços extras) — um erro de digitação silenciosamente quebra o layout, sem mensagem de erro.

- Resumo do Módulo

  • grid-template-areas permite desenhar o layout como um mapa de texto
  • repeat(auto-fit, minmax(...)) cria grades responsivas sem media query
  • grid-column/grid-row posicionam itens manualmente na grade
  • Grid organiza a página; Flexbox organiza o conteúdo dentro de cada peça
