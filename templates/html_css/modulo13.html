13. Design Responsivo e Mobile-First Avançado

No Módulo 6 você viu o básico de responsividade. Agora vamos aprofundar na estratégia mobile-first e em técnicas modernas que reduzem drasticamente o número de media queries necessárias.

- O que é Mobile-First, de Verdade

Mobile-first não é só "testar no celular" — é escrever o CSS base para telas pequenas primeiro, e usar min-width para adicionar complexidade conforme a tela cresce:

/* Base: já funciona perfeitamente no celular */
.container { display: block; padding: 16px; }

/* A partir de 768px, vira um grid de 2 colunas */
@media (min-width: 768px) {
    .container { display: grid; grid-template-columns: 1fr 1fr; }
}

/* A partir de 1024px, vira 3 colunas */
@media (min-width: 1024px) {
    .container { grid-template-columns: repeat(3, 1fr); }
}

Isso é o oposto do "desktop-first" (escrever para telas grandes e usar max-width para "desfazer" estilos em telas pequenas) — mobile-first resulta em CSS mais enxuto e sites mais rápidos em celulares, que são a maioria do tráfego.

- Unidades Fluidas: clamp(), vw, vh

h1 {
    /* mínimo 1.5rem, ideal 5vw, máximo 3rem — nunca fica pequeno OU gigante demais */
    font-size: clamp(1.5rem, 5vw, 3rem);
}
.hero { min-height: 60vh; }  /* 60% da altura da tela, sempre */

clamp(mínimo, ideal, máximo) é a ferramenta mais poderosa para tipografia responsiva: o texto cresce suavemente com a tela, mas nunca ultrapassa os limites definidos.

- Imagens Responsivas

img {
    max-width: 100%;
    height: auto;
    display: block;
}

Essa regra simples evita que imagens "estourem" o container em telas pequenas — deveria estar em praticamente todo projeto.

- Escondendo e Reorganizando Conteúdo

.menu-desktop { display: none; }
.menu-mobile  { display: block; }

@media (min-width: 900px) {
    .menu-desktop { display: flex; }
    .menu-mobile  { display: none; }
}

- Container Queries (novidade moderna)

Media queries reagem ao tamanho da tela inteira. Container queries reagem ao tamanho do elemento pai — útil para componentes reutilizáveis que podem aparecer em espaços de tamanhos diferentes:

.card-wrapper { container-type: inline-size; }

@container (min-width: 400px) {
    .card { display: flex; }   /* só vira flex se o CONTAINER tiver 400px+, não a tela */
}
Teste em tamanhos reais, não só redimensionando a janela
Use o modo de dispositivo do DevTools do navegador (F12 → ícone de celular) para testar em resoluções reais de celulares e tablets, não apenas encolhendo a janela do navegador no desktop.
Não esqueça a meta viewport
Sem <meta name="viewport" content="width=device-width, initial-scale=1.0"> no <head>, os celulares renderizam a página como se fosse desktop e depois encolhem — suas media queries simplesmente não vão funcionar como esperado.

- Resumo do Módulo

  • Mobile-first: escreva o CSS base para telas pequenas, use min-width para adicionar complexidade
  • clamp() cria tipografia e espaçamentos fluidos sem várias media queries
  • max-width: 100% em imagens evita overflow
  • Container queries reagem ao tamanho do elemento pai, não da tela inteira
