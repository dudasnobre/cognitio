1. Introdução ao HTML

HTML (HyperText Markup Language) é a estrutura de toda página da web. Ele não é uma linguagem de programação — é uma linguagem de marcação, que descreve o que cada parte do conteúdo é: um título, um parágrafo, uma imagem.

- A Estrutura Básica de uma Página

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Minha Página</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
</body>
</html>
  • <!DOCTYPE html> — avisa o navegador que é HTML5
  • <html> — elemento raiz de toda a página
  • <head> — metadados: título da aba, charset, links de CSS (não aparece na tela)
  • <body> — tudo que aparece visualmente na página

- O que é uma Tag?

Tags são os "blocos de construção" do HTML. A maioria vem em pares — abertura e fechamento:

<p>Isto é um parágrafo.</p>

Algumas tags não têm fechamento, pois não envolvem conteúdo (são "auto-fecháveis"):

<br>   <!-- quebra de linha -->
<img>  <!-- imagem -->
<hr>   <!-- linha horizontal -->

- Títulos e Parágrafos

<h1>Título Principal</h1>
<h2>Subtítulo</h2>
<h3>Título menor</h3>
<p>Um parágrafo de texto normal.</p>
Dica
Existem 6 níveis de título, de <h1> (mais importante) a <h6> (menos importante). Use apenas um <h1> por página — ele representa o assunto principal.

- Atributos

Atributos dão informações extras a uma tag, sempre dentro da tag de abertura:

<p class="destaque" id="intro">Texto especial</p>

- Comentários em HTML

Comentários não aparecem na página — servem para você (ou colegas de equipe) deixar anotações no código:

<!-- Isto é um comentário e não aparece na tela -->
<p>Isto aparece normalmente.</p>

- Como o Navegador Lê seu HTML

O navegador lê o arquivo de cima para baixo e monta uma estrutura em forma de árvore chamada DOM (Document Object Model) — cada tag vira um "nó" dessa árvore. É essa árvore que o CSS estiliza e o JavaScript manipula depois.

Erros comuns de quem está começando
  • Esquecer de fechar uma tag (ex: abrir <p> sem o </p> correspondente) — o navegador tenta adivinhar onde termina, e o resultado pode ficar bagunçado.
  • Aninhar tags fora de ordem: <b><i>texto</b></i> está errado — a última tag aberta deve ser a primeira a fechar: <b><i>texto</i></b>.
  • Usar aspas erradas em atributos: sempre use aspas retas ("), nunca aspas curvas do Word (" ").
