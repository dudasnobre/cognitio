16. Projeto Final: Construindo um Site Responsivo Completo

Chegou a hora de juntar tudo o que você aprendeu nos 15 módulos anteriores em um único projeto: uma landing page completa, semântica, responsiva, com tema personalizável e acessível.

- O Desafio

Construa uma landing page de uma página (pode ser para um produto, um evento ou um portfólio pessoal) que inclua:

  • ✅ HTML semântico completo (header, nav, main, section, footer)
  • ✅ Um cabeçalho com navegação usando Flexbox
  • ✅ Uma seção de conteúdo (cards de destaque) usando Grid
  • ✅ Cores e espaçamentos definidos com Custom Properties
  • ✅ Ao menos uma animação/transição sutil (hover em botões, entrada de seção)
  • ✅ Layout mobile-first, funcional em qualquer tamanho de tela
  • ✅ Contraste de cores adequado e foco visível em elementos interativos

- Estrutura Sugerida

<body>
  <header>
    <nav><!-- logo + links, flexbox --></nav>
  </header>

  <main>
    <section id="hero"><!-- título + chamada para ação --></section>
    <section id="destaques"><!-- grid de cards --></section>
    <section id="sobre"><!-- texto + imagem --></section>
  </main>

  <footer><!-- direitos autorais, redes sociais --></footer>
</body>

- Checklist de Qualidade Antes de Finalizar

Revise sua página
1. Navegue por Tab — chega em todos os links e botões?
2. Redimensione a janela — nada quebra ou "estoura" a tela?
3. Toda imagem tem alt?
4. Os títulos seguem uma hierarquia lógica (h1 → h2 → h3, sem pular níveis)?
5. As cores de texto têm contraste suficiente com o fundo?

- Use o Laboratório Abaixo

Monte seu projeto diretamente no laboratório interativo abaixo. Comece pelo esqueleto semântico, depois adicione o CSS aos poucos: primeiro o layout (Flexbox/Grid), depois as cores (variáveis), por último os toques finais (animações, hover).
