5. Flexbox e Grid

Flexbox e Grid são os dois sistemas modernos de layout do CSS. Eles resolveram, de vez, o problema de alinhar e distribuir elementos na tela — algo que era muito complicado nos primeiros anos da web.

- Flexbox: alinhando em uma linha ou coluna

.container {
    display: flex;
    justify-content: space-between;  /* eixo horizontal */
    align-items: center;             /* eixo vertical */
    gap: 16px;
}
  • display: flex — ativa o Flexbox no elemento pai
  • justify-content — alinha os filhos no eixo principal (flex-start, center, space-between, space-around)
  • align-items — alinha os filhos no eixo cruzado (flex-start, center, stretch)
  • flex-direction: column — muda a direção para vertical
  • gap — espaço entre os itens, sem precisar de margin

- Grid: linhas e colunas ao mesmo tempo

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

repeat(3, 1fr) cria 3 colunas de larguras iguais (1fr = uma "fração" do espaço disponível). Você também pode misturar tamanhos:

grid-template-columns: 200px 1fr 1fr;   /* uma coluna fixa + duas flexíveis */
Flexbox ou Grid?
Use Flexbox para alinhar itens em uma única direção (uma barra de navegação, por exemplo). Use Grid quando precisar controlar linhas E colunas ao mesmo tempo (uma galeria de cards, um dashboard).

- flex-wrap: Permitindo Quebra de Linha

Por padrão, o Flexbox tenta espremer todos os itens numa única linha. Para permitir que eles "quebrem" para a linha de baixo quando não couberem, use flex-wrap:

.container {
    display: flex;
    flex-wrap: wrap;   /* permite quebrar linha em vez de espremer */
    gap: 16px;
}

- grid-template-areas: Nomeando o Layout

Uma forma bastante visual de montar um layout de página inteira com Grid — você literalmente "desenha" onde cada seção vai:

.pagina {
    display: grid;
    grid-template-columns: 200px 1fr;
    grid-template-areas:
        "cabecalho cabecalho"
        "menu      conteudo";
}
header  { grid-area: cabecalho; }
nav     { grid-area: menu; }
main    { grid-area: conteudo; }
Erro comum: esquecer display: flex/grid no pai
Propriedades como justify-content e grid-template-columns só funcionam no elemento que tem display: flex ou display: grid. Escrever essas propriedades no elemento filho não faz nada.

- Resumo do Módulo

  • display: flex alinha itens numa única direção (linha ou coluna)
  • display: grid controla linhas e colunas simultaneamente
  • gap cria espaço entre itens sem precisar de margin
  • flex-wrap: wrap permite que itens quebrem para a próxima linha
