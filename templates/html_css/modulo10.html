10. Custom Properties (Variáveis CSS) e Temas

Variáveis CSS (oficialmente "Custom Properties") permitem definir um valor uma única vez e reutilizá-lo em toda a folha de estilo — a base de qualquer sistema de temas (claro/escuro, marcas personalizáveis) moderno.

- Declarando e Usando Variáveis

:root {
    --cor-primaria: #F77F00;
    --cor-texto: #1a1a1a;
    --espacamento: 16px;
    --radius: 12px;
}

.botao {
    background: var(--cor-primaria);
    padding: var(--espacamento);
    border-radius: var(--radius);
}

:root é o elemento raiz do documento — declarar variáveis ali as torna disponíveis em toda a página. O prefixo -- identifica uma custom property.

- var() com Valor de Fallback

.card {
    /* usa --cor-card se existir, senão usa branco */
    background: var(--cor-card, white);
}

- Tema Claro/Escuro Dinâmico

A grande vantagem das variáveis CSS sobre os pré-processadores (como Sass) é que elas podem ser alteradas em tempo real com JavaScript, sem recompilar nada:

/* CSS */
:root {
    --bg: #ffffff;
    --texto: #1a1a1a;
}
[data-tema="escuro"] {
    --bg: #12121a;
    --texto: #f0f0f0;
}
body { background: var(--bg); color: var(--texto); }
// JavaScript
document.body.dataset.tema = "escuro"; // troca o tema instantaneamente

- Escopo de Variáveis

Variáveis também podem ser redefinidas dentro de um seletor específico, afetando só aquele bloco e seus filhos:

.card-destaque {
    --cor-primaria: #D62828;  /* só dentro deste card, a variável vira vermelha */
}
Variáveis para tudo que se repete
Espaçamentos, cores, bordas arredondadas, sombras, tempos de transição — qualquer valor usado em mais de um lugar é candidato a virar variável. Isso torna o CSS muito mais fácil de manter.
Custom properties não são as mesmas que variáveis do Sass
Variáveis de pré-processador (Sass/LESS) são substituídas em tempo de compilação e viram valores fixos. Custom properties do CSS puro continuam "vivas" no navegador — por isso é possível trocá-las com JavaScript sem recarregar a página.

- Resumo do Módulo

  • --nome: valor; declara uma variável, geralmente dentro de :root
  • var(--nome, fallback) usa a variável, com um valor reserva opcional
  • Trocar variáveis via JavaScript permite temas dinâmicos sem recarregar a página
  • Variáveis podem ser redefinidas dentro de um seletor para mudar só aquele escopo
