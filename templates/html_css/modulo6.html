6. Responsividade e Boas Práticas

Uma página bem feita precisa funcionar tão bem no celular quanto no computador. Vamos fechar o curso com responsividade e um checklist de boas práticas para levar para os seus próprios projetos.

- A Meta Tag Viewport

Sem ela, navegadores mobile renderizam a página como se fosse desktop e depois "encolhem" tudo. Ela já deve estar em toda página que você criar:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

- Media Queries

Permitem aplicar CSS diferente dependendo do tamanho da tela:

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr;   /* uma coluna só em telas pequenas */
    }
}
Dica: mobile-first
Uma boa prática é escrever o CSS pensando primeiro no celular (telas pequenas) e depois usar media queries com min-width para adicionar estilos conforme a tela cresce.

- Unidades Flexíveis

width: 100%;      /* relativo ao elemento pai */
font-size: 1.2rem; /* relativo ao tamanho de fonte raiz (html) */
max-width: 600px;  /* nunca ultrapassa esse valor, mas encolhe */

Prefira %, rem e max-width a valores fixos em px sempre que possível — isso deixa o layout muito mais adaptável.

- Checklist de Boas Práticas

  • Use tags semânticas: <header>, <nav>, <main>, <footer> em vez de só <div>
  • Sempre preencha o alt das imagens
  • Um único <h1> por página
  • CSS em arquivo externo, nunca inline em projetos reais
  • Teste sempre em telas pequenas (ou reduza a janela do navegador)
  • Nomeie classes de forma descritiva: .card-produto, não .div1

- Imagens Responsivas

Sem cuidado, uma imagem grande pode "estourar" o layout em telas pequenas. A regra mais simples e eficaz:

img {
    max-width: 100%;
    height: auto;
}
Por que isso funciona
max-width: 100% impede a imagem de ultrapassar a largura do elemento pai, e height: auto mantém a proporção original — a imagem encolhe junto com a tela, sem distorcer.

- Breakpoints Comuns do Mercado

Não existe uma regra fixa, mas estes valores são um bom ponto de partida usado amplamente:

@media (max-width: 480px)  { /* celulares */ }
@media (max-width: 768px)  { /* tablets */ }
@media (max-width: 1024px) { /* laptops pequenos */ }
Não esqueça a meta viewport
Media queries simplesmente não funcionam direito sem a tag <meta name="viewport"> vista no início deste módulo — é o erro mais comum de quem está aprendendo responsividade.
