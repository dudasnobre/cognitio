8. Flexbox Avançado

Você já conhece o básico do Flexbox. Agora vamos além: controlar o crescimento individual dos itens, permitir quebra de linha e montar padrões de layout usados em praticamente todo site profissional.

- flex-grow, flex-shrink e flex-basis

Essas três propriedades controlam como cada item individual se comporta dentro do container flex — geralmente escritas juntas no atalho flex:

.item {
    flex: 1 1 200px;
    /*     |  |  |
           |  |  flex-basis: tamanho "ideal" de partida
           |  flex-shrink: o quanto pode encolher (1 = pode)
           flex-grow: o quanto pode crescer para ocupar espaço extra
    */
}
  • flex: 1 — atalho para "cresça igualmente, dividindo o espaço"
  • flex: 0 0 200px — item com largura fixa de 200px, não cresce nem encolhe
  • flex-grow: 2 — este item cresce o dobro em relação a um irmão com flex-grow: 1

- flex-wrap e Layouts que Quebram Linha

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
}
.card { flex: 1 1 240px; }  /* cada card tenta ter 240px, mas encolhe/quebra se precisar */

Esse padrão — flex-wrap: wrap + flex-basis em cada item — é a forma mais comum de criar uma grade de cards responsiva sem escrever uma única media query.

- order: Mudando a Ordem Visual

.item-destaque { order: -1; }  /* aparece primeiro, mesmo sendo o último no HTML */

Útil para, por exemplo, mostrar a imagem antes do texto no celular e depois do texto no desktop — sem duplicar HTML.

- Padrão: Navbar com Flexbox

.navbar {
    display: flex;
    align-items: center;
    justify-content: space-between;
}
.navbar .links { display: flex; gap: 20px; }

- Padrão: Holy Grail Layout (cabeçalho, 3 colunas, rodapé)

.pagina { display: flex; flex-direction: column; min-height: 100vh; }
.corpo  { display: flex; flex: 1; }
.corpo aside { flex: 0 0 220px; }   /* colunas laterais fixas */
.corpo main  { flex: 1; }           /* coluna central flexível */
align-self
Precisa que só um item tenha um alinhamento diferente dos demais? Use align-self nele em vez de mudar o align-items do container inteiro.
flex-basis vs width
Quando flex-grow ou flex-shrink estão ativos, flex-basis tem prioridade sobre width. Se seu item não está respeitando a largura que você definiu, verifique se não há um flex-basis conflitante.

- Resumo do Módulo

  • flex: grow shrink basis controla o comportamento individual de cada item
  • flex-wrap: wrap + flex-basis cria grades responsivas sem media queries
  • order muda a ordem visual sem tocar no HTML
  • Navbars e layouts de 3 colunas são os padrões mais comuns do Flexbox no mundo real
