3. Formulários e Tabelas

Formulários coletam dados do usuário (login, cadastro, contato) e tabelas organizam informação em linhas e colunas. São dois dos elementos mais usados em sistemas reais.

- Estrutura de um Formulário

<form action="/enviar" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome">

    <label for="email">E-mail:</label>
    <input type="email" id="email" name="email">

    <button type="submit">Enviar</button>
</form>
Dica
Sempre associe <label> ao campo com for="id_do_input" — além de ajudar leitores de tela, clicar no texto do label foca automaticamente o campo.

- Tipos de Input

<input type="text">       <!-- texto livre -->
<input type="email">      <!-- valida formato de e-mail -->
<input type="password">   <!-- oculta os caracteres -->
<input type="number">     <!-- só números -->
<input type="checkbox">   <!-- caixa de seleção -->
<input type="radio">      <!-- escolha única entre opções -->
<input type="date">       <!-- seletor de data -->

- Select (menu suspenso) e Textarea

<select name="curso">
    <option value="html">HTML & CSS</option>
    <option value="python">Python</option>
</select>

<textarea rows="4" placeholder="Escreva sua mensagem..."></textarea>

- Tabelas

<table>
    <thead>
        <tr>
            <th>Nome</th>
            <th>Idade</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Ana</td>
            <td>25</td>
        </tr>
    </tbody>
</table>
  • <table> — a tabela inteira
  • <tr> — uma linha (table row)
  • <th> — célula de cabeçalho (table header)
  • <td> — célula comum (table data)

- Atributos Importantes de Validação

<input type="text" required>              <!-- campo obrigatório -->
<input type="text" placeholder="Seu nome"> <!-- texto de exemplo -->
<input type="number" min="0" max="120">    <!-- limite de valores -->
<input type="text" maxlength="20">         <!-- limite de caracteres -->
Validação HTML não é suficiente sozinha
Atributos como required ajudam a experiência do usuário, mas nunca confie só neles para segurança — sempre valide os dados também no servidor (back-end), pois um usuário mal-intencionado pode burlar validações do navegador.

- Agrupando Opções com fieldset

<fieldset>
    <legend>Escolha seu curso</legend>
    <label><input type="radio" name="curso" value="html"> HTML & CSS</label>
    <label><input type="radio" name="curso" value="python"> Python</label>
</fieldset>
Erro comum: radios com name diferente
Botões de opção (radio) só funcionam como grupo de escolha única se todos tiverem o mesmo valor no atributo name. Se cada um tiver um name diferente, o usuário poderá marcar vários ao mesmo tempo.

- Resumo do Módulo

  • <form> agrupa campos; <label> conecta um texto ao campo via for
  • Diferentes type de <input> validam formatos diferentes (email, número, data...)
  • <table>, <tr>, <th> e <td> estruturam dados tabulares
  • Validação HTML (required, min, max) melhora a UX, mas não substitui validação no servidor
