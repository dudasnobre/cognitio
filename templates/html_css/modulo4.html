4. Introdução ao CSS

CSS (Cascading Style Sheets) é o que transforma um HTML sem graça em uma página bonita: cores, espaçamentos, fontes e posicionamento. A partir de agora, HTML estrutura e CSS estiliza.

- 3 Formas de Aplicar CSS

<!-- 1. Inline (direto na tag, evite usar sempre) -->
<p style="color: red;">Texto vermelho</p>

<!-- 2. Interno (dentro do <head>) -->
<style>
    p { color: red; }
</style>

<!-- 3. Externo (recomendado — arquivo .css separado) -->
<link rel="stylesheet" href="estilo.css">
Dica
Use sempre CSS externo em projetos reais — mantém o HTML limpo e permite reaproveitar o mesmo estilo em várias páginas (é assim que esta plataforma funciona!).

- Seletores

p { }              /* todas as tags <p> */
.destaque { }      /* todo elemento com class="destaque" */
#titulo { }        /* o elemento com id="titulo" */
p.destaque { }     /* <p> que também tenha a classe destaque */
div p { }          /* todo <p> dentro de um <div> */

- Cores e Texto

h1 {
    color: #306998;
    font-size: 32px;
    font-family: Arial, sans-serif;
    text-align: center;
    font-weight: bold;
}

- O Box Model

Todo elemento HTML é uma caixa retangular, composta por quatro camadas:

div {
    width: 200px;
    padding: 20px;    /* espaço interno, entre o conteúdo e a borda */
    border: 2px solid #333;
    margin: 10px;     /* espaço externo, entre a caixa e outros elementos */
}
  • content — o conteúdo em si (texto, imagem)
  • padding — respiro interno
  • border — a borda da caixa
  • margin — respiro externo, entre elementos
Pegadinha clássica do Box Model
Por padrão, width: 200px mede só o conteúdo — padding e border são somados por fora, então a caixa real fica maior que 200px! A solução usada por quase todo projeto moderno é adicionar box-sizing: border-box;, que faz o width já incluir padding e border. 
* {
    box-sizing: border-box; /* aplique isso no início de todo projeto */
}

- Especificidade: Qual Regra Vence?

Quando duas regras CSS tentam estilizar o mesmo elemento, existe uma ordem de prioridade — dos mais fracos aos mais fortes:

  1. Seletor de tag (p) — o mais fraco
  2. Seletor de classe (.destaque)
  3. Seletor de id (#titulo)
  4. Estilo inline (style="...") — o mais forte
Regra prática
Se seu CSS "não está funcionando", quase sempre é uma questão de especificidade — outra regra mais forte está vencendo a sua. Evite estilo inline e !important justamente para não perder o controle dessa hierarquia.

- Herança de Propriedades

Algumas propriedades (como color e font-family) são herdadas automaticamente pelos elementos filhos, sem precisar repetir a regra:

body {
    font-family: Arial, sans-serif; /* todo texto da página herda essa fonte */
    color: #333;
}

- Resumo do Módulo

  • CSS externo (via <link>) é sempre a melhor prática
  • Seletores de tag, classe e id têm níveis de especificidade diferentes
  • Todo elemento é uma caixa: content → padding → border → margin
  • box-sizing: border-box; evita a surpresa da largura crescer sozinha
