7. HTML Semântico e Estrutura Acessível

Até aqui você usou <div> para quase tudo. Mas o HTML tem tags que descrevem o significado do conteúdo, não só sua aparência. Isso se chama HTML semântico — e ele é essencial para SEO, acessibilidade e organização do código.

- Por que não usar só <div>?

Uma <div> não diz nada sobre o que ela contém. Leitores de tela, motores de busca e outros desenvolvedores não sabem se aquela div é um menu, um rodapé ou o conteúdo principal. As tags semânticas resolvem isso:

<body>
  <header>...</header>
  <nav>...</nav>
  <main>
    <article>...</article>
    <aside>...</aside>
  </main>
  <footer>...</footer>
</body>

- As Principais Tags Semânticas

  • <header> — cabeçalho da página ou de uma seção
  • <nav> — bloco de navegação (menus, links principais)
  • <main> — conteúdo principal da página (único por página)
  • <section> — agrupa conteúdo relacionado sob um mesmo tema
  • <article> — conteúdo independente (um post, uma notícia)
  • <aside> — conteúdo complementar (barra lateral, dica)
  • <footer> — rodapé da página ou de uma seção
Regra prática
Se existe uma tag semântica que descreve o bloco que você está criando, use-a. Só volte para <div> quando nenhuma tag semântica se encaixar (por exemplo, um wrapper puramente visual).

- Introdução à Acessibilidade (a11y)

HTML semântico já é a base da acessibilidade: leitores de tela usam essas tags para montar um "mapa" da página que a pessoa pode navegar por atalhos de teclado. Duas práticas simples que fazem enorme diferença:

<img src="grafico.png" alt="Gráfico de vendas crescendo 40% em 2025">

<button aria-label="Fechar janela">
  <i class="icone-x"></i>
</button>
  • alt em imagens — descreve a imagem para quem não pode vê-la
  • aria-label — dá um nome acessível a elementos sem texto visível (ícones)
Erro comum: usar <h1> a <h6> pela aparência
Não escolha um heading pelo tamanho da fonte que ele produz — escolha pela hierarquia real do conteúdo. Se precisar de um título menor visualmente, use CSS; não pule de <h1> direto para <h4> só porque "ficou do tamanho certo".
