4. Funções

Funções são blocos de código reutilizáveis. Em vez de repetir o mesmo código várias vezes, você o encapsula numa função, dá um nome a ela e chama quando precisar. São o coração da programação modular.

- Declaração de Função (function declaration)

function saudar(nome) {
    return `Olá, ${nome}!`;
}

console.log(saudar("Ana"));   // Olá, Ana!
console.log(saudar("Carlos")); // Olá, Carlos!

- Expressão de Função (function expression)

const dobrar = function(n) {
    return n * 2;
};
console.log(dobrar(5));  // 10

- Arrow Functions (ES6+)

Sintaxe moderna e concisa. Se o corpo tem apenas um return, pode omitir as chaves:

const quadrado = (n) => n * n;
const soma = (a, b) => a + b;
const cumprimentar = nome => `Oi, ${nome}!`;  // parênteses opcionais com 1 parâmetro

console.log(quadrado(4));       // 16
console.log(soma(3, 7));        // 10
console.log(cumprimentar("Bia")); // Oi, Bia!

- Parâmetros Padrão

function potencia(base, expoente = 2) {
    return base ** expoente;
}
console.log(potencia(3));    // 9  (usa expoente padrão)
console.log(potencia(2, 10)); // 1024

- Escopo

Variáveis declaradas dentro de uma função só existem dentro dela (escopo local). Variáveis fora da função são globais:

let global = "sou global";

function teste() {
    let local = "sou local";
    console.log(global); // acessível
    console.log(local);  // acessível
}
teste();
// console.log(local); // ❌ ReferenceError

- Loops com Funções

for (let i = 1; i <= 5; i++) {
    console.log(`Contagem: ${i}`);
}

let n = 0;
while (n < 3) {
    console.log(`while: ${n}`);
    n++;
}
Arrow vs function tradicional
Use arrow functions para callbacks e código curto. Use function quando precisar de this próprio (ex: métodos de objeto) ou funções que serão elevadas (hoisting).

- Rest Parameters (...args)

Quando você não sabe quantos argumentos serão passados, use ... para reuni-los num array:

function somarTudo(...numeros) {
    return numeros.reduce((total, n) => total + n, 0);
}
console.log(somarTudo(1, 2, 3));        // 6
console.log(somarTudo(10, 20, 30, 40)); // 100

- Funções que Retornam Funções (Closures)

Uma função pode "lembrar" do ambiente onde foi criada, mesmo depois de a função externa já ter terminado — isso se chama closure:

function criarContador() {
    let contagem = 0;
    return function () {
        contagem++;
        return contagem;
    };
}
const contador = criarContador();
console.log(contador()); // 1
console.log(contador()); // 2
console.log(contador()); // 3
Por que isso é útil
Closures são a base de muitos padrões em JS — desde contadores privados até o funcionamento de hooks do React. Não se preocupe em dominar 100% agora, só reconheça o padrão quando vir de novo.
Função sem return devolve undefined
Assim como em outras linguagens, esquecer o return não gera erro — a função simplesmente devolve undefined, o que costuma causar bugs silenciosos.
