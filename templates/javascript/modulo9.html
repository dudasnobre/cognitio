9. Armazenamento no Navegador (localStorage)

Toda aplicação web precisa "lembrar" de algo entre visitas: preferências, um carrinho de compras, o progresso de um curso. O localStorage guarda dados diretamente no navegador, sem precisar de um servidor.

- Guardando e Lendo Dados

localStorage.setItem('nome', 'Ana');
console.log(localStorage.getItem('nome')); // "Ana"

localStorage.removeItem('nome');
localStorage.clear(); // apaga tudo
localStorage só guarda texto (strings)
Se tentar guardar um número ou objeto diretamente, ele será convertido para string automaticamente — e não da forma que você espera. Use JSON.stringify/JSON.parse para objetos e arrays.

- Guardando Objetos e Arrays com JSON

const usuario = { nome: 'Ana', nivel: 3, favoritos: ['JS', 'CSS'] };

// Salvar: transforma o objeto em texto JSON
localStorage.setItem('usuario', JSON.stringify(usuario));

// Ler: transforma o texto JSON de volta em objeto
const salvo = JSON.parse(localStorage.getItem('usuario'));
console.log(salvo.nome, salvo.favoritos);

- Padrão: Estado Persistente Simples

function salvarProgresso(modulo) {
    const progresso = JSON.parse(localStorage.getItem('progresso') || '[]');
    if (!progresso.includes(modulo)) progresso.push(modulo);
    localStorage.setItem('progresso', JSON.stringify(progresso));
}

function carregarProgresso() {
    return JSON.parse(localStorage.getItem('progresso') || '[]');
}

salvarProgresso('modulo1');
console.log(carregarProgresso());

Esse é, na prática, o mesmo padrão que a Cognitio usa para guardar seu progresso, XP e conquistas no navegador!

- localStorage vs sessionStorage

  • localStorage — persiste mesmo depois de fechar o navegador
  • sessionStorage — some quando a aba é fechada; útil para dados temporários
Nunca guarde dados sensíveis
localStorage é acessível por qualquer script rodando na página e não é criptografado. Nunca guarde senhas, tokens sensíveis ou dados de pagamento nele.

- Resumo do Módulo

  • localStorage.setItem/getItem/removeItem/clear — API básica
  • JSON.stringify/JSON.parse são obrigatórios para objetos e arrays
  • Sempre trate o caso de o dado ainda não existir (|| '[]', || '{}')
