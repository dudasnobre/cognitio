11. Boas Práticas, Debugging e Tratamento de Erros

Escrever código que funciona é o primeiro passo. Escrever código fácil de depurar quando algo dá errado é o que separa um projeto sustentável de um pesadelo de manutenção.

- try/catch/finally

function dividir(a, b) {
    if (b === 0) {
        throw new Error('Divisão por zero não é permitida');
    }
    return a / b;
}

try {
    console.log(dividir(10, 0));
} catch (erro) {
    console.error('Algo deu errado:', erro.message);
} finally {
    console.log('Isso sempre executa, com erro ou sem.');
}

- Criando Erros Customizados

class ErroDeValidacao extends Error {
    constructor(mensagem) {
        super(mensagem);
        this.name = 'ErroDeValidacao';
    }
}

function validarIdade(idade) {
    if (idade < 0) throw new ErroDeValidacao('Idade não pode ser negativa');
    return idade;
}

- Métodos Úteis do console

console.log('informação normal');
console.warn('um aviso');
console.error('um erro');
console.table([{ nome: 'Ana', nota: 9 }, { nome: 'Bruno', nota: 7 }]);
console.time('operacao');
// ... código a medir ...
console.timeEnd('operacao'); // mostra quanto tempo levou

- Debugando com o DevTools

  • debugger; no código pausa a execução ali, se o DevTools estiver aberto
  • Clique no número da linha no painel "Sources" do navegador para adicionar um breakpoint sem editar o código
  • Use "Step over/into" para executar o código linha a linha e inspecionar variáveis

- Código Defensivo

function calcularMedia(notas) {
    if (!Array.isArray(notas) || notas.length === 0) {
        console.warn('calcularMedia: array inválido ou vazio');
        return 0;
    }
    return notas.reduce((soma, n) => soma + n, 0) / notas.length;
}

Verificar entradas antes de processá-las evita que erros silenciosos se propaguem para partes distantes do código, onde ficam muito mais difíceis de rastrear.

Mensagens de erro específicas economizam horas
throw new Error('Erro') ajuda pouco. throw new Error('Idade deve ser um número entre 0 e 120, recebido: ' + idade) economiza muito tempo de depuração no futuro — inclusive o seu.
Nunca ignore um catch silenciosamente
Um bloco catch (e) {} vazio esconde erros que deveriam ser corrigidos. No mínimo, registre o erro com console.error(e) para saber que algo aconteceu.

- Resumo do Módulo

  • try/catch/finally trata erros sem quebrar a aplicação inteira
  • throw new Error(mensagem) cria erros descritivos e rastreáveis
  • console.table, console.time e breakpoints aceleram a depuração
  • Valide entradas de funções para evitar erros silenciosos
