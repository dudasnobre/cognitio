1. Introdução ao JavaScript

JavaScript é a linguagem de programação da web — ela roda diretamente no navegador e é responsável por tudo que se move, reage e interage numa página. Junto com HTML e CSS, forma a tríade fundamental do desenvolvimento web.

- O que é JavaScript?

JavaScript (JS) é uma linguagem de programação interpretada, dinâmica e multiparadigma. Criada em 1995 por Brendan Eich em apenas 10 dias, hoje é a linguagem mais usada do mundo segundo pesquisas anuais do Stack Overflow.

  • Roda no navegador (front-end) e no servidor com Node.js (back-end)
  • Permite criar páginas dinâmicas, jogos, apps mobile (React Native) e APIs
  • Não precisa de instalação — todo navegador já tem um motor JS
  • Sintaxe inspirada em C/Java, mas muito mais flexível

- Seu Primeiro Código

O console.log() é o print do JavaScript — exibe valores no console do navegador (e no nosso terminal abaixo):

console.log("Olá, Mundo!");
console.log(2 + 2);
console.log(true);

- Onde o JS vive?

No navegador, você insere JS numa página HTML com a tag <script>:

<script>
  console.log("JS embutido no HTML");
</script>

<!-- Ou como arquivo externo: -->
<script src="meu-script.js"></script>

- Como o Navegador Executa seu Código

Cada navegador tem um motor JavaScript embutido — o Chrome e o Edge usam o V8 (o mesmo que roda o Node.js), o Firefox usa o SpiderMonkey. Esse motor lê seu código, o transforma em instruções que a máquina entende e executa, tudo isso em milissegundos, sem você precisar instalar nada.

Abra o console do seu navegador
Pressione F12 (ou Ctrl+Shift+I) em qualquer página e vá na aba "Console" — é um REPL de JavaScript de verdade, rodando ao vivo na página que você está vendo.

- Erros Comuns de Quem Está Começando

Fique de olho nestas armadilhas
  • Esquecer o ponto e vírgula ; no fim das instruções — o JS costuma tolerar, mas é boa prática usar sempre.
  • Confundir = com ===: um = atribui; === compara valor e tipo ao mesmo tempo.
  • Chaves { } ou parênteses ( ) sem fechar — geram SyntaxError e às vezes travam blocos inteiros de código.
  • JavaScript é case-sensitive: Nome e nome são variáveis totalmente diferentes.
