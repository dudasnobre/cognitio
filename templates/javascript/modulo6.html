6. DOM — Manipulando a Página

O DOM (Document Object Model) é a representação da página HTML como uma árvore de objetos JavaScript. Com ele você pode ler, criar, modificar e remover elementos HTML em tempo real — é isso que torna as páginas interativas.

- Selecionando Elementos

// Retorna o primeiro elemento que bate com o seletor CSS
const titulo = document.querySelector('h1');
const btn    = document.querySelector('#meu-botao');
const cards  = document.querySelectorAll('.card'); // NodeList (todos)

// Formas antigas (ainda úteis)
document.getElementById('id');
document.getElementsByClassName('classe');

- Lendo e Modificando Conteúdo

const p = document.querySelector('p');

// Ler
console.log(p.textContent);  // texto puro
console.log(p.innerHTML);    // HTML interno

// Modificar
p.textContent = "Novo texto";
p.innerHTML   = "Texto com negrito";

- Modificando Estilos e Classes

const box = document.querySelector('.box');

// Estilos inline
box.style.backgroundColor = '#f0b429';
box.style.borderRadius    = '8px';

// Classes (recomendado)
box.classList.add('destaque');
box.classList.remove('antigo');
box.classList.toggle('ativo');      // adiciona/remove
box.classList.contains('ativo');    // true/false

- Criando e Inserindo Elementos

// Cria o elemento
const novoItem = document.createElement('li');
novoItem.textContent = 'Item dinâmico';
novoItem.classList.add('item');

// Insere na página
const lista = document.querySelector('ul');
lista.appendChild(novoItem);   // no final
lista.prepend(novoItem);       // no início
lista.removeChild(novoItem);   // remove

- Atributos

const img = document.querySelector('img');
img.setAttribute('alt', 'Imagem de exemplo');
img.getAttribute('src');
img.removeAttribute('hidden');

- Navegando pela Árvore DOM

Todo elemento HTML tem relações de parentesco que você pode percorrer via JavaScript:

const item = document.querySelector('.item');

item.parentElement;       // o elemento "pai"
item.children;            // os elementos "filhos" diretos
item.nextElementSibling;  // o próximo elemento "irmão"
item.previousElementSibling; // o elemento "irmão" anterior
textContent vs innerHTML
Use innerHTML apenas quando o conteúdo for confiável (não vindo de um input de usuário) — inserir HTML não sanitizado é uma porta aberta para ataques XSS. Para texto puro, prefira sempre textContent.
Nota sobre o terminal
Nosso terminal JS executa em sandbox sem acesso ao DOM desta página para não causar conflitos. Para praticar DOM, abra o DevTools do seu navegador (F12 → Console) e experimente os comandos acima diretamente na página!
