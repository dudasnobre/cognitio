3. Operadores e Condicionais

Operadores permitem fazer cálculos e comparações. Condicionais permitem que o programa tome decisões diferentes dependendo dos dados — é o que torna o código inteligente.

- Operadores Aritméticos

5 + 3   // 8   — adição
10 - 4  // 6   — subtração
6 * 7   // 42  — multiplicação
15 / 4  // 3.75 — divisão
15 % 4  // 3   — módulo (resto da divisão)
2 ** 8  // 256 — exponenciação

- Operadores de Comparação

Sempre retornam true ou false. Prefira === e !== (comparam valor e tipo):

5 === 5       // true  (igualdade estrita)
5 == "5"      // true  (igualdade fraca — evite)
5 !== 6       // true
10 > 8        // true
10 <= 10      // true

- Operadores Lógicos

true && false   // false  — AND (ambos precisam ser true)
true || false   // true   — OR  (basta um ser true)
!true           // false  — NOT (inverte)

- if / else if / else

const nota = 75;

if (nota >= 90) {
    console.log("Aprovado com distinção!");
} else if (nota >= 60) {
    console.log("Aprovado.");
} else {
    console.log("Reprovado.");
}

- Operador Ternário

Forma compacta de um if/else em uma linha:

const idade = 20;
const status = idade >= 18 ? "Maior de idade" : "Menor de idade";
console.log(status); // Maior de idade

- switch

const dia = "segunda";
switch (dia) {
    case "segunda": console.log("Início da semana!"); break;
    case "sexta":   console.log("Quase fim de semana!"); break;
    default:        console.log("Dia comum.");
}
=== vs ==
Sempre use ===. O operador == faz conversão de tipo automática e pode causar bugs difíceis de encontrar: 0 == false é true com ==, mas false com ===.

- Truthy e Falsy

Dentro de um if, o JavaScript converte qualquer valor para true ou false. Só estes valores são considerados falsy — todo o resto é truthy:

false, 0, "", null, undefined, NaN   // falsy — tudo o resto é truthy

if ("") console.log("nunca roda");
if ("0") console.log("roda! string '0' é truthy");
if ([]) console.log("roda! array vazio é truthy");

- Operadores de Curto-Circuito (&& e ||)

Além de combinar condições, && e || são muito usados para valores padrão e execução condicional:

const nome = usuario.nome || "Visitante";  // usa "Visitante" se nome for falsy
usuario.logado && console.log("Bem-vindo!"); // só executa se logado for truthy

// Operador de coalescência nula (??) — só cai no padrão se for null/undefined
const idade = usuario.idade ?? 18;
