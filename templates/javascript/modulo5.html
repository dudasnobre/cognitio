5. Arrays e Objetos

Arrays e objetos são as estruturas de dados mais importantes do JavaScript. Arrays guardam listas ordenadas; objetos guardam pares chave-valor — juntos, representam quase qualquer dado do mundo real.

- Arrays: listas ordenadas

const frutas = ["maçã", "banana", "laranja"];
console.log(frutas[0]);        // "maçã"  (índice começa em 0)
console.log(frutas.length);    // 3
frutas.push("uva");            // adiciona no final
frutas.pop();                  // remove o último
frutas.unshift("abacaxi");     // adiciona no início
frutas.shift();                // remove o primeiro

- Métodos Modernos de Array

const numeros = [1, 2, 3, 4, 5];

// forEach — percorre sem retornar
numeros.forEach(n => console.log(n));

// map — transforma e retorna novo array
const dobrados = numeros.map(n => n * 2);
console.log(dobrados); // [2, 4, 6, 8, 10]

// filter — filtra por condição
const pares = numeros.filter(n => n % 2 === 0);
console.log(pares); // [2, 4]

// reduce — acumula em um valor
const soma = numeros.reduce((acc, n) => acc + n, 0);
console.log(soma); // 15

// find — retorna o primeiro que satisfaz
const primeiroPar = numeros.find(n => n % 2 === 0);
console.log(primeiroPar); // 2

- Objetos: pares chave-valor

const pessoa = {
    nome: "Ana",
    idade: 28,
    cidade: "Fortaleza",
    saudar() {
        return `Oi, sou ${this.nome}!`;
    }
};

console.log(pessoa.nome);      // Ana
console.log(pessoa["idade"]);  // 28
console.log(pessoa.saudar());  // Oi, sou Ana!

- Destructuring

Extrai valores de arrays/objetos de forma elegante:

// Array destructuring
const [a, b, c] = [10, 20, 30];
console.log(a, b, c); // 10 20 30

// Object destructuring
const { nome, idade } = { nome: "Carlos", idade: 32 };
console.log(nome, idade); // Carlos 32

- Spread e Rest

// Spread — expande um array/objeto
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];
console.log(arr2); // [1, 2, 3, 4, 5]

// Rest — coleta o restante dos argumentos
function soma(...numeros) {
    return numeros.reduce((a, b) => a + b, 0);
}
console.log(soma(1, 2, 3, 4)); // 10
map, filter, reduce
Esses três métodos são a base da programação funcional em JS. Aprenda-os bem — eles substituem a maioria dos loops manuais e tornam o código mais legível e declarativo.

- Encadeando Métodos (Method Chaining)

Como map, filter e outros métodos devolvem um novo array, você pode encadeá-los em sequência para transformar dados em poucas linhas:

const produtos = [
    { nome: "Caderno", preco: 15 },
    { nome: "Caneta", preco: 3 },
    { nome: "Mochila", preco: 120 }
];

const caros = produtos
    .filter(p => p.preco > 10)
    .map(p => p.nome.toUpperCase());

console.log(caros); // ["CADERNO", "MOCHILA"]

- Object.keys, values e entries

const pessoa = { nome: "Ana", idade: 28 };

console.log(Object.keys(pessoa));    // ["nome", "idade"]
console.log(Object.values(pessoa));  // ["Ana", 28]
console.log(Object.entries(pessoa)); // [["nome","Ana"], ["idade",28]]
Cuidado ao copiar objetos/arrays
const copia = original; não cria uma cópia — só aponta para o mesmo objeto na memória! Para copiar de verdade, use spread: const copia = { ...original }; ou [...arrayOriginal].
Exercício rápido
No terminal, crie um array de objetos representando 3 alunos (nome e nota). Use filter para pegar só os aprovados (nota >= 6) e map para exibir só os nomes deles.

- Resumo do Módulo

  • Arrays guardam listas ordenadas; map/filter/reduce são os métodos mais usados
  • Objetos guardam pares chave-valor e podem ter métodos próprios
  • Destructuring extrai valores de arrays/objetos com sintaxe curta
  • Spread (...) expande e copia; Rest (...) coleta argumentos
