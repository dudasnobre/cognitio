8. Manipulação Avançada do DOM e Formulários

Agora que você sabe selecionar e alterar elementos, vamos trabalhar com formulários de verdade: capturar valores, validar antes de enviar e criar elementos dinamicamente a partir de dados.

- Capturando Dados de um Formulário

const form = document.querySelector('#meu-form');

form.addEventListener('submit', function(e) {
    e.preventDefault(); // impede o recarregamento da página
    const dados = new FormData(form);
    console.log(dados.get('nome'), dados.get('email'));
});

- Validação Simples no Cliente

function validarEmail(email) {
    return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}

form.addEventListener('submit', e => {
    e.preventDefault();
    const email = form.email.value;
    if (!validarEmail(email)) {
        alert('E-mail inválido!');
        return;
    }
    console.log('Formulário válido, enviando...');
});
Validação no cliente não substitui a do servidor
Validar no navegador melhora a experiência (feedback instantâneo), mas nunca confie só nela — sempre valide os dados novamente no back-end, já que o JavaScript do cliente pode ser burlado.

- Criando Elementos Dinamicamente a partir de Dados

const produtos = [
    { nome: 'Caderno', preco: 12.5 },
    { nome: 'Caneta', preco: 3.0 }
];

const lista = document.querySelector('#lista-produtos');
produtos.forEach(p => {
    const li = document.createElement('li');
    li.textContent = `${p.nome} - R$ ${p.preco.toFixed(2)}`;
    lista.appendChild(li);
});

- template Element (evitando innerHTML repetitivo)

<template id="modelo-card">
  <div class="card"><h3></h3></div>
</template>
const modelo = document.querySelector('#modelo-card');
const clone = modelo.content.cloneNode(true);
clone.querySelector('h3').textContent = 'Novo Card';
document.body.appendChild(clone);
Cuidado com innerHTML e dados do usuário
Inserir texto de um usuário diretamente com innerHTML pode abrir brechas de segurança (XSS). Prefira textContent para texto simples, e só use innerHTML com conteúdo confiável.

- Resumo do Módulo

  • FormData captura todos os campos de um formulário de uma vez
  • Sempre chame e.preventDefault() para controlar o envio manualmente
  • Gere listas de elementos a partir de arrays de dados com forEach + createElement
  • Prefira textContent a innerHTML quando o conteúdo vem do usuário
