10. JavaScript Moderno (ES6+)

Desde 2015 (ES6), o JavaScript ganhou recursos que tornam o código mais curto, mais legível e menos propenso a erros. Todo código profissional atual usa esses recursos o tempo todo.

- Template Literals

const nome = 'Ana';
const idade = 28;

// Antes:
const msg1 = 'Olá, ' + nome + '! Você tem ' + idade + ' anos.';
// Agora:
const msg2 = `Olá, ${nome}! Você tem ${idade} anos.`;

// Também permite múltiplas linhas facilmente:
const html = `
  

    
${nome}

  

`;

- Destructuring (Desestruturação)

const pessoa = { nome: 'Bruno', idade: 30, cidade: 'SP' };
const { nome, cidade } = pessoa;
console.log(nome, cidade); // Bruno SP

const cores = ['vermelho', 'verde', 'azul'];
const [primeira, segunda] = cores;
console.log(primeira); // vermelho

// Muito usado em parâmetros de função:
function apresentar({ nome, idade }) {
    console.log(`${nome} tem ${idade} anos`);
}

- Spread e Rest (...)

// Spread: "espalha" os elementos
const a = [1, 2, 3];
const b = [...a, 4, 5]; // [1, 2, 3, 4, 5]

const config = { tema: 'claro' };
const configCompleta = { ...config, idioma: 'pt-br' };

// Rest: agrupa argumentos restantes em um array
function somarTudo(...numeros) {
    return numeros.reduce((total, n) => total + n, 0);
}
console.log(somarTudo(1, 2, 3, 4)); // 10

- Operadores Modernos

const usuario = null;

// Optional chaining: acessa com segurança, sem quebrar em null/undefined
console.log(usuario?.perfil?.nome); // undefined, sem erro

// Nullish coalescing: usa o valor à direita só se a esquerda for null/undefined
const tema = usuario?.tema ?? 'claro';
console.log(tema); // 'claro'

- Módulos ES (import/export)

// arquivo utils.js
export function formatarPreco(valor) {
    return `R$ ${valor.toFixed(2)}`;
}

// arquivo main.js
import { formatarPreco } from './utils.js';
console.log(formatarPreco(19.9));

Módulos permitem dividir o código em arquivos organizados por responsabilidade, importando apenas o que é necessário em cada um.

?. e ?? evitam muitos "if" de verificação
Antes do optional chaining, era comum escrever if (usuario && usuario.perfil && usuario.perfil.nome). Hoje isso vira uma única linha com usuario?.perfil?.nome.

- Resumo do Módulo

  • Template literals (`texto ${variavel}`) substituem concatenação de strings
  • Destructuring extrai valores de objetos/arrays em variáveis diretamente
  • Spread (...) espalha elementos; rest agrupa argumentos
  • ?. e ?? tornam o código mais seguro contra valores ausentes
