2. Variáveis e Tipos de Dados

Variáveis são caixas com nome onde guardamos informações para usar depois. Em JavaScript temos três formas de declarar variáveis — cada uma com um comportamento diferente.

- let, const e var

  • const — valor imutável; use sempre que o valor não precisar mudar
  • let — valor mutável; use quando o valor pode ser atualizado
  • var — forma antiga, tem comportamentos confusos (evite em código novo)
const nome = "Ana";          // não muda
let idade = 25;              // pode mudar
idade = 26;                  // OK!
// nome = "Carlos";          // ❌ ERRO — const não aceita reatribuição

- Os 7 Tipos Primitivos

  • string — texto: "olá", 'mundo', `template`
  • number — inteiros e decimais: 42, 3.14, -7
  • boolean — verdadeiro/falso: true, false
  • undefined — variável declarada mas sem valor
  • null — ausência intencional de valor
  • bigint — números inteiros gigantes: 9007199254740991n
  • symbol — identificador único (avançado)

- Template Literals (strings modernas)

Com acentos graves (`) você pode interpolar variáveis diretamente na string:

const nome = "Carlos";
const idade = 30;
console.log(`Olá, ${nome}! Você tem ${idade} anos.`);
// Olá, Carlos! Você tem 30 anos.

- Conversão de Tipos

Number("42")      // → 42
String(100)       // → "100"
Boolean(0)        // → false  (0, "", null, undefined são falsy)
Boolean("hello")  // → true
Dica: prefira const
Use const por padrão. Só troque para let quando souber que o valor vai mudar (ex: contador, acumulador). Isso torna o código mais previsível.

- Operadores Aritméticos

const soma = 10 + 3;         // 13
const sub  = 10 - 3;          // 7
const mul  = 10 * 3;          // 30
const div  = 10 / 3;          // 3.333...
const resto = 10 % 3;         // 1 (resto da divisão)
const pot  = 10 ** 2;         // 100 (potência)

let contador = 0;
contador++;                    // incrementa 1 (contador = 1)
contador += 5;                 // soma 5 (contador = 6)
Cuidado ao somar tipos diferentes
"5" + 3 resulta em "53" (concatenação de texto), não 8! O operador + se comporta como soma matemática só quando ambos os lados são number. Use Number() para converter antes de somar.
