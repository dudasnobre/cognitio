3. Estruturas Condicionais

Estruturas condicionais permitem que o programa tome decisões: "se isso acontecer, faça aquilo". É aqui que a lógica de programação realmente começa.

- if, elif e else

idade = 20

if idade < 12:
    print("Você é uma criança")
elif idade < 18:
    print("Você é adolescente")
else:
    print("Você é adulto")
>>> Você é adulto
  • if — testa a primeira condição
  • elif — testa outras condições (pode repetir várias vezes)
  • else — executa se nenhuma condição anterior for verdadeira
A indentação importa!
Diferente de outras linguagens, Python usa a indentação (espaços) para definir blocos de código — não chaves { }. Use sempre 4 espaços por nível.

- Operadores de Comparação

==   igual a
!=   diferente de
>    maior que
<    menor que
>=   maior ou igual
<=   menor ou igual

- Operadores Lógicos

idade = 25
tem_carteira = True

if idade >= 18 and tem_carteira:
    print("Pode dirigir")

if idade < 18 or not tem_carteira:
    print("Não pode dirigir")
  • and — verdadeiro só se AMBAS as condições forem verdadeiras
  • or — verdadeiro se PELO MENOS uma condição for verdadeira
  • not — inverte o valor (True vira False)

- Condicional em uma linha (ternário)

idade = 17
status = "maior" if idade >= 18 else "menor"
print(status)
>>> menor

- Condições Aninhadas

Você pode colocar um if dentro de outro quando a decisão depende de mais de um nível de verificação:

usuario_logado = True
saldo = 150

if usuario_logado:
    if saldo > 0:
        print("Bem-vindo! Saldo disponível.")
    else:
        print("Bem-vindo! Mas seu saldo está zerado.")
else:
    print("Faça login primeiro.")
Nem sempre precisa aninhar
O exemplo acima também poderia ser escrito com and: if usuario_logado and saldo > 0:. Prefira and/or quando possível — o código fica mais curto e mais fácil de ler.
Erro comum: esquecer os dois-pontos
Toda linha que abre um bloco (if, elif, else) precisa terminar com :. Esquecer isso é a causa nº 1 de SyntaxError para quem está começando.
Exercício rápido
Escreva um programa que peça uma nota (0 a 10) com input() e imprima "Aprovado" se a nota for maior ou igual a 6, "Recuperação" se estiver entre 4 e 5.9, e "Reprovado" caso contrário.

- Resumo do Módulo

  • if / elif / else controlam o fluxo do programa com base em condições
  • Operadores de comparação (==, !=, >, <...) retornam sempre True ou False
  • and, or e not combinam várias condições
  • O operador ternário resolve condicionais simples em uma linha
