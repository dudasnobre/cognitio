4. Laços de Repetição

Laços (loops) repetem um bloco de código várias vezes — essenciais para processar listas, validar entradas ou repetir tarefas sem copiar e colar código.

- for — repetindo um número definido de vezes

for i in range(5):
    print(i)
>>> 0 >>> 1 >>> 2 >>> 3 >>> 4

range(5) gera os números de 0 a 4 (o 5 não entra). Você também pode definir início, fim e passo:

for i in range(2, 10, 2):
    print(i)   # 2, 4, 6, 8

- for percorrendo uma lista ou texto

frutas = ["maçã", "banana", "uva"]
for fruta in frutas:
    print(fruta)

for letra in "Python":
    print(letra)

- while — repetindo enquanto uma condição for verdadeira

contador = 0
while contador < 3:
    print(f"Contando: {contador}")
    contador += 1
>>> Contando: 0 >>> Contando: 1 >>> Contando: 2
Cuidado com loops infinitos
Se você esquecer de atualizar a variável de controle (contador += 1), o while nunca vai parar. Sempre garanta que a condição possa se tornar falsa em algum momento.

- break e continue

for i in range(10):
    if i == 5:
        break        # para o loop completamente
    if i % 2 == 0:
        continue     # pula para a próxima repetição
    print(i)
>>> 1 >>> 3

- Loops Aninhados

Um loop dentro de outro é útil para percorrer combinações — como linhas e colunas de uma tabela:

for linha in range(1, 4):
    for coluna in range(1, 4):
        print(f"({linha},{coluna})", end=" ")
    print()  # pula linha ao final de cada linha externa
>>> (1,1) (1,2) (1,3) >>> (2,1) (2,2) (2,3) >>> (3,1) (3,2) (3,3)
Tabuada com loop aninhado
Um clássico exercício de loop aninhado é gerar a tabuada de 1 a 10: o loop externo escolhe o número, o interno multiplica de 1 a 10.

- A Cláusula else no Loop

Pouca gente sabe, mas for e while em Python podem ter um else — ele roda quando o loop termina normalmente, sem ter passado por um break:

numeros = [2, 4, 6, 8]
for n in numeros:
    if n % 2 != 0:
        print("Achei um ímpar!")
        break
else:
    print("Todos os números são pares.")
>>> Todos os números são pares.
range() não inclui o valor final
range(1, 5) gera 1, 2, 3, 4 — muita gente espera que o 5 apareça e se surpreende quando ele não entra no resultado.
Exercício rápido
Escreva um programa com while que peça números ao usuário e os some, parando quando ele digitar 0. No final, mostre o total somado.

- Resumo do Módulo

  • for repete um número definido de vezes ou percorre uma sequência
  • while repete enquanto uma condição continuar verdadeira
  • break interrompe o loop; continue pula para a próxima repetição
  • Loops podem ser aninhados e até ter um else próprio
