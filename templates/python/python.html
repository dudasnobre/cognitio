1. Introdução ao Python

Python é uma das linguagens de programação mais usadas do mundo — simples de ler, poderosa o suficiente para ciência de dados, automação, inteligência artificial e desenvolvimento web. Vamos começar do absoluto zero.

- O que é Python?

Criado por Guido van Rossum em 1991, o Python é uma linguagem interpretada, de alto nível e multiparadigma. Sua sintaxe foi pensada para se parecer com inglês simples, o que torna o aprendizado muito mais natural para quem está começando.

  • Usado por empresas como Google, Netflix, Instagram e NASA
  • Base de frameworks como Flask e Django (web) e Pandas/TensorFlow (dados e IA)
  • Não precisa de ponto e vírgula nem chaves — a indentação organiza o código
  • Roda em Windows, Linux e macOS

- Instalando o Python

No Linux, o Python já costuma vir instalado. Para verificar a versão, abra o terminal e digite:

python3 --version

Se não estiver instalado, no Debian/Ubuntu (e derivados, como o seu Policorp OEM):

sudo apt update
sudo apt install python3 python3-pip
Dica
No Windows, baixe o instalador em python.org/downloads e marque a opção "Add Python to PATH" durante a instalação — isso evita boa parte dos erros de iniciante.

- Seu Primeiro Programa

A função print() exibe qualquer coisa na tela. É o "Olá, Mundo!" de toda linguagem:

print("Olá, Mundo!")
print(2 + 2)
print(True)
>>> Olá, Mundo! >>> 4 >>> True

- Como Executar um Arquivo Python

Crie um arquivo chamado ola.py com o código acima e execute pelo terminal:

python3 ola.py

- Comentários

Comentários são ignorados pelo interpretador — servem para explicar o código para humanos:

# Isso é um comentário de uma linha

"""
Isso é um comentário
de múltiplas linhas
"""

- Como o Python Executa seu Código

Python é uma linguagem interpretada: não existe uma etapa separada de "compilação" que você precisa rodar antes. O interpretador lê seu arquivo .py de cima para baixo e vai executando linha por linha, na hora. É por isso que testar uma ideia rápida em Python é tão mais ágil do que em linguagens compiladas como C ou Java.

  • Você escreve código em um arquivo .py (ou digita direto no terminal)
  • O interpretador python3 traduz cada linha para instruções que o computador entende
  • Se houver um erro de sintaxe, a execução para exatamente naquele ponto — por isso os erros mostram o número da linha

- O Modo Interativo (REPL)

Digite apenas python3 no terminal (sem nome de arquivo) para abrir o REPL — Read-Eval-Print Loop. É um terminal onde cada linha que você digita é executada na hora, ótimo para testar pequenos trechos:

$ python3
>>> 10 + 5
15
>>> nome = "Cognitio"
>>> print(f"Olá, {nome}!")
Olá, Cognitio!
>>> exit()
Use o REPL para experimentar
Sempre que tiver dúvida se um trecho de código funciona, teste primeiro no REPL antes de colocar no seu arquivo .py — é mais rápido que salvar e rodar o arquivo toda vez.

- Erros Comuns de Quem Está Começando

Fique de olho nestas armadilhas
  • Indentação inconsistente: Python usa espaços para definir blocos de código — misturar tabs e espaços causa IndentationError.
  • Esquecer os dois-pontos : ao abrir blocos como if, for e funções.
  • Confundir = com ==: um único = atribui um valor; dois == comparam valores.
  • Misturar aspas simples e duplas sem fechar corretamente a string.
