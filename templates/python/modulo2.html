2. Variáveis e Tipos de Dados

Variáveis guardam informações para usar depois. Em Python, você não precisa declarar o tipo — o interpretador descobre sozinho, o que chamamos de tipagem dinâmica.

- Criando Variáveis

nome = "Ana"
idade = 25
altura = 1.68
esta_ativo = True
  • Nomes de variáveis usam snake_case (letras minúsculas e underscore): nome_completo
  • Não podem começar com número nem ter espaços
  • Python diferencia maiúsculas de minúsculas: idade e Idade são variáveis diferentes

- Os Tipos de Dados Básicos

  • str — texto: "olá", 'mundo'
  • int — números inteiros: 42, -7
  • float — números decimais: 3.14, -0.5
  • bool — verdadeiro/falso: True, False
  • NoneType — ausência de valor: None

Use a função type() para descobrir o tipo de qualquer valor:

print(type(nome))
print(type(idade))
print(type(altura))
>>> <class 'str'> >>> <class 'int'> >>> <class 'float'>

- Atribuição Múltipla e Constantes

Python permite atribuir vários valores em uma única linha — útil para deixar o código mais enxuto:

nome, idade, cidade = "Ana", 25, "Fortaleza"
x = y = z = 0   # os três recebem o mesmo valor

Python não tem uma palavra-chave própria para constantes (como const), mas por convenção usamos letras maiúsculas para sinalizar que um valor não deve mudar:

PI = 3.14159
LIMITE_MAXIMO = 100

- Operadores Aritméticos

Antes de seguir em frente, vale conhecer os operadores matemáticos que você vai usar o tempo todo:

soma = 10 + 3        # 13
sub  = 10 - 3         # 7
mul  = 10 * 3         # 30
div  = 10 / 3         # 3.333... (sempre retorna float)
div_inteira = 10 // 3 # 3  (descarta a parte decimal)
resto = 10 % 3        # 1  (resto da divisão)
pot  = 10 ** 2        # 100 (potência)
Divisão: / vs //
/ sempre devolve um número decimal (float), mesmo quando o resultado é exato. Se você precisa de um número inteiro na divisão, use //.

- f-strings (interpolação de texto)

A forma moderna de inserir variáveis dentro de um texto é com f"":

nome = "Carlos"
idade = 30
print(f"Olá, {nome}! Você tem {idade} anos.")
>>> Olá, Carlos! Você tem 30 anos.

- Conversão de Tipos

int("42")      # → 42
str(100)       # → "100"
float("3.14")  # → 3.14
bool(0)        # → False   (0, "", None são "falsy")
bool("oi")     # → True

- Recebendo Dados do Usuário

A função input() pausa o programa e espera o usuário digitar algo — o retorno é sempre texto (str), então normalmente convertemos:

nome = input("Qual é o seu nome? ")
idade = int(input("Qual é a sua idade? "))
print(f"{nome} tem {idade} anos.")
Dica: nomeie bem suas variáveis
x = 25 funciona, mas idade = 25 deixa o código muito mais fácil de entender — inclusive para você mesmo, daqui a um mês.
Cuidado com o tipo errado
Tentar somar um número com um texto gera erro: "idade: " + 25 quebra com TypeError. Converta primeiro: "idade: " + str(25) — ou, melhor ainda, use uma f-string.
Exercício rápido
Crie três variáveis — preco (float), quantidade (int) e produto (str) — e imprima com uma f-string a frase: "3 unidades de Caderno custam R$ 15.90". Calcule o total (preco * quantidade) e mostre também.

- Resumo do Módulo

  • Variáveis guardam valores e não precisam de tipo declarado
  • str, int, float, bool e None são os tipos básicos
  • f-strings (f"{variavel}") são a forma moderna de compor textos
  • input() sempre retorna texto — converta quando precisar de número
