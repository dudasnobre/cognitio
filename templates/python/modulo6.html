6. Funções

Funções agrupam um bloco de código que pode ser reutilizado quantas vezes forem necessárias, evitando repetição e organizando melhor o programa.

- Criando uma função

def saudacao(nome):
    print(f"Olá, {nome}! Seja bem-vindo(a).")

saudacao("Marcos")
saudacao("Julia")
>>> Olá, Marcos! Seja bem-vindo(a). >>> Olá, Julia! Seja bem-vindo(a).

- Retornando valores com return

def somar(a, b):
    return a + b

resultado = somar(5, 3)
print(resultado)
>>> 8

return devolve um valor e encerra a função imediatamente — diferente de print(), que só exibe algo na tela sem devolver nada para ser usado depois.

- Parâmetros com valor padrão

def saudacao(nome, saudacao_texto="Olá"):
    print(f"{saudacao_texto}, {nome}!")

saudacao("Ana")                 # usa o padrão "Olá"
saudacao("Ana", "Bom dia")      # sobrescreve o padrão

- Argumentos nomeados (keyword arguments)

def criar_perfil(nome, idade, cidade):
    print(f"{nome}, {idade} anos, mora em {cidade}")

criar_perfil(nome="Bia", cidade="Recife", idade=22)

Com argumentos nomeados, a ordem deixa de importar — o Python casa cada valor pelo nome.

- Escopo de variáveis

x = 10   # variável global

def teste():
    x = 5   # variável local, só existe dentro da função
    print(x)

teste()
print(x)
>>> 5 >>> 10
Boas práticas
Dê às suas funções nomes que descrevam o que elas fazem (verbos): calcular_media(), enviar_email(). Isso torna o código autoexplicativo.

- *args e **kwargs (número variável de argumentos)

Às vezes você não sabe de antemão quantos valores serão passados para a função. *args recebe qualquer quantidade de argumentos posicionais como uma tupla, e **kwargs recebe argumentos nomeados como um dicionário:

def somar_tudo(*numeros):
    return sum(numeros)

print(somar_tudo(1, 2, 3))       # 6
print(somar_tudo(10, 20, 30, 40)) # 100

def exibir_perfil(**dados):
    for chave, valor in dados.items():
        print(f"{chave}: {valor}")

exibir_perfil(nome="Léo", idade=19, cidade="Recife")

- Funções Lambda

Funções pequenas e anônimas, escritas em uma linha — úteis quando você precisa de uma função rápida e descartável, geralmente como argumento de outra função:

dobro = lambda x: x * 2
print(dobro(5))    # 10

# Muito comum junto de sorted() para definir o critério de ordenação
alunos = [("Bia", 22), ("Léo", 19), ("Ana", 26)]
alunos_por_idade = sorted(alunos, key=lambda a: a[1])
print(alunos_por_idade)
lambda vs def
lambda só pode conter uma expressão (sem if com blocos, sem múltiplas linhas). Para qualquer coisa mais elaborada, uma função normal com def é mais legível.

- Documentando Funções com Docstrings

Uma docstring é um texto entre """ logo abaixo do def, explicando o que a função faz — boas ferramentas e editores mostram esse texto automaticamente:

def calcular_media(notas):
    """Recebe uma lista de notas e retorna a média aritmética."""
    return sum(notas) / len(notas)
Função sem return devolve None
Se você esquecer o return, a função ainda "funciona", mas o valor devolvido será None — um erro silencioso muito comum entre iniciantes.
Exercício rápido
Escreva uma função eh_par(numero) que retorna True ou False. Depois, use-a dentro de uma list comprehension para filtrar só os números pares de uma lista de 1 a 20.

- Resumo do Módulo

  • Funções são criadas com def e podem receber parâmetros e devolver valores com return
  • Parâmetros podem ter valor padrão e podem ser passados por nome (keyword arguments)
  • *args e **kwargs lidam com número variável de argumentos
  • lambda cria funções curtas e anônimas para uso pontual
