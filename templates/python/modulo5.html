5. Listas, Tuplas e Dicionários

Estruturas de dados guardam várias informações de uma vez. São a base de praticamente todo programa Python — de uma lista de compras a um banco de dados inteiro em memória.

- Listas (list)

Coleções ordenadas e mutáveis — você pode adicionar, remover e alterar itens:

frutas = ["maçã", "banana", "uva"]
print(frutas[0])       # maçã (índice começa em 0)
print(frutas[-1])      # uva (último item)

frutas.append("manga")     # adiciona no final
frutas.remove("banana")    # remove pelo valor
print(len(frutas))         # tamanho da lista
>>> maçã >>> uva >>> 3

- Fatiamento (slicing)

numeros = [10, 20, 30, 40, 50]
print(numeros[1:3])    # [20, 30]
print(numeros[:2])     # [10, 20]
print(numeros[2:])     # [30, 40, 50]

- Tuplas (tuple)

Assim como listas, mas imutáveis — depois de criadas, não podem ser alteradas. Ótimas para dados que não devem mudar, como coordenadas:

coordenada = (10.5, -20.3)
print(coordenada[0])
# coordenada[0] = 5  ❌ ERRO — tupla não aceita alteração

- Dicionários (dict)

Guardam dados em pares de chave: valor — como uma ficha de cadastro:

aluno = {
    "nome": "Ana",
    "idade": 25,
    "curso": "Python"
}
print(aluno["nome"])
aluno["idade"] = 26          # atualiza um valor
aluno["cidade"] = "Fortaleza"  # adiciona uma nova chave

for chave, valor in aluno.items():
    print(f"{chave}: {valor}")
>>> Ana >>> nome: Ana >>> idade: 26 >>> curso: Python >>> cidade: Fortaleza
Quando usar cada uma?
Lista quando a ordem importa e os dados podem mudar. Tupla quando os dados são fixos. Dicionário quando você precisa nomear cada informação (como campos de um formulário).

- Métodos Úteis de Lista

numeros = [5, 2, 8, 1]
numeros.sort()              # ordena: [1, 2, 5, 8]
numeros.reverse()           # inverte: [8, 5, 2, 1]
numeros.insert(0, 100)      # insere 100 no índice 0
print(3 in numeros)         # verifica se o valor existe → False
print(numeros.index(2))     # posição do valor 2

- Compreensão de Lista (List Comprehension)

Uma forma compacta e muito usada por programadores Python de criar listas a partir de outra sequência:

# Forma tradicional
quadrados = []
for n in range(1, 6):
    quadrados.append(n ** 2)

# Com list comprehension (mesma coisa, uma linha)
quadrados = [n ** 2 for n in range(1, 6)]
print(quadrados)   # [1, 4, 9, 16, 25]

# Com condição
pares = [n for n in range(1, 11) if n % 2 == 0]
print(pares)        # [2, 4, 6, 8, 10]
Não é obrigatório usar agora
List comprehension é um recurso "pythônico" muito comum em código real, mas o loop tradicional funciona igualmente bem. Use a forma com a qual você se sentir mais confortável enquanto ainda está aprendendo.

- Métodos Úteis de Dicionário

aluno = {"nome": "Ana", "idade": 26}

print(aluno.get("curso", "Não informado"))  # evita erro se a chave não existir
print(aluno.keys())     # todas as chaves
print(aluno.values())   # todos os valores
aluno.pop("idade")      # remove a chave "idade"
Acessar chave inexistente quebra o programa
aluno["curso"] gera KeyError se a chave não existir. Prefira aluno.get("curso"), que devolve None (ou um valor padrão) em vez de travar o programa.
Exercício rápido
Crie uma lista de dicionários representando 3 produtos, cada um com nome e preco. Percorra a lista com um for e imprima o nome de todos os produtos com preço acima de R$ 50.

- Resumo do Módulo

  • Listas são ordenadas e mutáveis — append, remove, sort
  • Tuplas são como listas, mas imutáveis
  • Dicionários guardam pares chave:valor e usam .get() para acesso seguro
  • List comprehension cria listas de forma compacta em uma linha
