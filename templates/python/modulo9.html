9. Programação Orientada a Objetos: Introdução

Até agora você organizou dados em variáveis e dicionários separados. Classes permitem agrupar dados e comportamento relacionados em um único "molde" reutilizável — a base da Programação Orientada a Objetos (POO).

- Criando uma Classe

class Aluno:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

    def apresentar(self):
        return f"Oi, eu sou {self.nome} e tenho {self.idade} anos."

aluno1 = Aluno("Laura", 28)
print(aluno1.apresentar())
  • class Aluno: — define o "molde" para criar objetos do tipo Aluno
  • __init__ — método especial chamado automaticamente ao criar um objeto
  • self — representa a instância atual do objeto (obrigatório no primeiro parâmetro de todo método)

- Atributos e Métodos

class ContaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, valor):
        self.saldo += valor

    def sacar(self, valor):
        if valor > self.saldo:
            print("Saldo insuficiente!")
            return
        self.saldo -= valor

conta = ContaBancaria("Bruno")
conta.depositar(500)
conta.sacar(150)
print(f"Saldo de {conta.titular}: R$ {conta.saldo}")

- Múltiplos Objetos, Mesma Classe

alunos = [
    Aluno("Ana", 22),
    Aluno("Bruno", 25),
    Aluno("Carla", 19)
]

for aluno in alunos:
    print(aluno.apresentar())

Cada objeto criado a partir da classe tem seus próprios valores de nome e idade, mesmo compartilhando o mesmo método apresentar().

- __str__: Representação Legível do Objeto

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    def __str__(self):
        return f"{self.nome} - R$ {self.preco:.2f}"

p = Produto("Caderno", 12.5)
print(p)  # usa __str__ automaticamente: "Caderno - R$ 12.50"
Quando usar classes?
Quando você percebe que está repetindo o mesmo grupo de variáveis relacionadas (nome+idade+curso de vários alunos, por exemplo) junto com funções que operam sobre elas, é sinal de que uma classe deixaria o código mais organizado.

- Resumo do Módulo

  • Classes agrupam dados (atributos) e comportamento (métodos) relacionados
  • __init__ inicializa cada novo objeto criado a partir da classe
  • self refere-se sempre à instância atual
  • __str__ personaliza como o objeto aparece em print()
