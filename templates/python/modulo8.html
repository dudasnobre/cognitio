8. Tratamento de Erros e Depuração

Erros acontecem — arquivos que não existem, divisões por zero, dados no formato errado. Python oferece um sistema robusto para lidar com essas situações sem que o programa simplesmente pare de funcionar.

- try / except

try:
    idade = int(input("Digite sua idade: "))
    print(f"Você tem {idade} anos")
except ValueError:
    print("Isso não é um número válido!")

O código dentro de try é executado normalmente. Se um erro do tipo especificado acontecer, o Python pula direto para o bloco except correspondente, em vez de travar o programa.

- Tipos Comuns de Exceção

  • ValueError — valor com tipo certo mas conteúdo inválido (ex: int("abc"))
  • ZeroDivisionError — divisão por zero
  • FileNotFoundError — arquivo não encontrado
  • KeyError — chave inexistente em um dicionário
  • IndexError — índice fora dos limites de uma lista

- Capturando Múltiplos Tipos de Erro

try:
    resultado = 10 / int(input("Divisor: "))
    print(resultado)
except ValueError:
    print("Digite um número válido!")
except ZeroDivisionError:
    print("Não é possível dividir por zero!")
except Exception as erro:
    print(f"Erro inesperado: {erro}")

- else e finally

try:
    numero = int("42")
except ValueError:
    print("Erro na conversão")
else:
    print("Conversão deu certo:", numero)  # só roda se NÃO houve erro
finally:
    print("Isso roda sempre, com erro ou sem")  # limpeza, fechar arquivos, etc.

- Lançando Seus Próprios Erros

def sacar(saldo, valor):
    if valor > saldo:
        raise ValueError("Saldo insuficiente para este saque")
    return saldo - valor

try:
    novo_saldo = sacar(100, 500)
except ValueError as e:
    print(f"Operação negada: {e}")
Seja específico com except
Capturar except: (sem especificar o tipo) esconde até erros de digitação no seu código. Sempre que possível, capture o tipo exato de exceção que você espera.
Não use try/except para controlar o fluxo normal
Tratamento de erros é para o inesperado. Se uma condição é previsível (ex: verificar se uma lista está vazia), prefira um if simples em vez de provocar e capturar uma exceção.
Exercício final
Escreva uma função dividir_seguro(a, b) que retorna o resultado da divisão, ou uma mensagem de erro amigável caso b seja zero ou não numérico.

- Resumo do Módulo

  • try/except evita que erros travem o programa inteiro
  • Capture tipos específicos de exceção sempre que possível
  • else roda se não houve erro; finally roda sempre
  • raise permite lançar seus próprios erros com mensagens claras
