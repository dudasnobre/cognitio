7. Arquivos, Módulos e Próximos Passos

Para fechar o curso, vamos aprender a ler e gravar arquivos, importar módulos prontos da biblioteca padrão e conhecer o caminho a seguir depois do básico.

- Escrevendo em um arquivo

with open("dados.txt", "w") as arquivo:
    arquivo.write("Primeira linha\n")
    arquivo.write("Segunda linha\n")

with open(...) as arquivo: garante que o arquivo será fechado automaticamente, mesmo se ocorrer um erro no meio do caminho — é a forma recomendada de trabalhar com arquivos em Python.

  • "w" — escreve (apaga o conteúdo anterior, se existir)
  • "a" — adiciona ao final do arquivo, sem apagar
  • "r" — apenas leitura

- Lendo um arquivo

with open("dados.txt", "r") as arquivo:
    conteudo = arquivo.read()
    print(conteudo)

# Ou linha por linha:
with open("dados.txt", "r") as arquivo:
    for linha in arquivo:
        print(linha.strip())

- Importando módulos

Python vem com uma biblioteca padrão enorme, pronta para usar com import:

import random
import datetime

print(random.randint(1, 10))     # número aleatório entre 1 e 10
print(datetime.date.today())     # data de hoje

- Organizando seu próprio código em módulos

Qualquer arquivo .py pode ser importado por outro. Se você tem um arquivo utils.py com uma função somar():

from utils import somar
print(somar(2, 3))

- Tratamento de Exceções (try / except)

Em vez de deixar o programa travar quando algo dá errado — como o usuário digitar texto onde se esperava um número — você pode capturar o erro e decidir o que fazer:

try:
    idade = int(input("Digite sua idade: "))
    print(f"Você tem {idade} anos.")
except ValueError:
    print("Isso não parece um número válido!")
finally:
    print("Obrigado por usar o programa.")

Você pode capturar tipos específicos de erro (ValueError, ZeroDivisionError, KeyError...) ou usar except Exception para pegar qualquer erro:

try:
    resultado = 10 / 0
except ZeroDivisionError:
    print("Não é possível dividir por zero!")
except Exception as erro:
    print(f"Algo deu errado: {erro}")
Por que isso importa
Programas reais lidam com entradas imprevisíveis o tempo todo — arquivos que não existem, conexões de internet que caem, usuários que digitam qualquer coisa. try/except é o que separa um script frágil de um programa confiável.

- Ambientes Virtuais (venv)

Quando seus projetos começam a usar bibliotecas de terceiros (como o Flask ou o Groq usados nesta plataforma), é boa prática isolar as dependências de cada projeto num ambiente virtual, evitando conflitos entre versões:

python3 -m venv .venv          # cria o ambiente
source .venv/bin/activate      # ativa (Linux/macOS)
pip install flask               # instala pacotes só dentro do ambiente
deactivate                      # sai do ambiente virtual

- Um gostinho de Orientação a Objetos

class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

    def apresentar(self):
        print(f"Oi, eu sou {self.nome} e tenho {self.idade} anos.")

p1 = Pessoa("Laura", 28)
p1.apresentar()
>>> Oi, eu sou Laura e tenho 28 anos.
