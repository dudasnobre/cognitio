10. Projeto Final: Automatizando uma Tarefa Real

Chegou a hora de juntar tudo: variáveis, condicionais, laços, listas/dicionários, funções, arquivos e tratamento de erros em um script Python que resolve um problema real do dia a dia.

- O Desafio: Organizador de Gastos Pessoais

Vamos construir um script que lê uma lista de gastos, calcula totais por categoria e salva um relatório em arquivo — algo muito próximo do que scripts de automação fazem no mercado de trabalho.

- Passo 1: Estrutura de Dados

gastos = [
    {"descricao": "Mercado", "valor": 250.00, "categoria": "Alimentação"},
    {"descricao": "Uber", "valor": 35.50, "categoria": "Transporte"},
    {"descricao": "Cinema", "valor": 60.00, "categoria": "Lazer"},
    {"descricao": "Padaria", "valor": 18.90, "categoria": "Alimentação"},
]

- Passo 2: Função para Agrupar por Categoria

def total_por_categoria(gastos):
    totais = {}
    for gasto in gastos:
        categoria = gasto["categoria"]
        totais[categoria] = totais.get(categoria, 0) + gasto["valor"]
    return totais

resultado = total_por_categoria(gastos)
for categoria, total in resultado.items():
    print(f"{categoria}: R$ {total:.2f}")

- Passo 3: Tratando Erros de Entrada

def adicionar_gasto(lista, descricao, valor, categoria):
    try:
        valor = float(valor)
        if valor < 0:
            raise ValueError("O valor não pode ser negativo")
        lista.append({"descricao": descricao, "valor": valor, "categoria": categoria})
        print(f"Gasto '{descricao}' adicionado com sucesso!")
    except ValueError as e:
        print(f"Erro ao adicionar gasto: {e}")

- Passo 4: Salvando um Relatório em Arquivo

def gerar_relatorio(gastos, nome_arquivo="relatorio.txt"):
    totais = total_por_categoria(gastos)
    total_geral = sum(g["valor"] for g in gastos)

    with open(nome_arquivo, "w") as arquivo:
        arquivo.write("=== RELATÓRIO DE GASTOS ===\n\n")
        for categoria, total in totais.items():
            arquivo.write(f"{categoria}: R$ {total:.2f}\n")
        arquivo.write(f"\nTOTAL GERAL: R$ {total_geral:.2f}\n")

    print(f"Relatório salvo em {nome_arquivo}!")

gerar_relatorio(gastos)

- Passo 5: Juntando Tudo em um Menu Interativo

def menu():
    gastos = []
    while True:
        print("\n1. Adicionar gasto\n2. Ver relatório\n3. Sair")
        opcao = input("Escolha: ")

        if opcao == "1":
            desc = input("Descrição: ")
            valor = input("Valor: ")
            cat = input("Categoria: ")
            adicionar_gasto(gastos, desc, valor, cat)
        elif opcao == "2":
            gerar_relatorio(gastos)
        elif opcao == "3":
            print("Até logo!")
            break
        else:
            print("Opção inválida, tente novamente.")

# menu()  # descomente para rodar interativamente no seu computador
Este padrão está em toda automação real
Ler dados → processar/agrupar → tratar erros de entrada → salvar um resultado. Esse é o esqueleto de praticamente qualquer script de automação de tarefas repetitivas, seja organizando gastos, arquivos ou relatórios de trabalho.
